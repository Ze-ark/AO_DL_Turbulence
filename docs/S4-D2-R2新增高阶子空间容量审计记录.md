# S4-D2-R2 新增高阶子空间容量审计记录

## 先说结论

正式新增高阶子空间容量实验完整结束并通过审计。当前可以确认：前10维继续由冻结传统控制器负责时，第11维以后的高阶方向客观存在可利用的理想动作。

21维方案中的新增11维使桶内功率平均相对提高6.6165%；36维方案中的新增26维提高9.3167%。两种表示在六个硬件误差档位中都通过原2%门槛。按照预先声明的选择规则，下一步优先研究更简单、违规率更低的新增11维方案，不直接训练新增26维方案。

这个结果不是RL成功。容量实验使用了未来仿真真值、精确配准参数和逐回合事后最优预见帧，只能证明“正确的高阶动作存在”，不能证明现有观测足以推断这些动作。

## 可以和不能说明什么

可以确认：

1. 新增高阶方向不是无效动作空间；
2. 旧SAC失败不能归因于“第11维以后根本没有可用动作”；
3. 新增11维已提供足够的理想收益余量，值得进行观测可学习性诊断；
4. 21维总表示比36维更适合作为下一步主线，因为学习输出只有新增11维，且安全负担更小。

尚不能确认：

- 现有4帧带噪观测能否预测新增11维理想动作；
- 失败来自部分可观测、标量奖励信用分配，还是SAC优化；
- 修订后的SAC、TD3或PPO谁更好；
- 仿真结果能否迁移到两台`FSLM-2K73-P04`。

## 统计谬误检查

覆盖：11/11。六个硬件档位和三个动态条件方向一致，未发现辛普森反转、缺失回合或生存者偏差。需要谨慎的两点是：容量实验使用未来信息和逐回合事后选择，属于乐观上限；多种预见帧比较不能当作可部署算法的正式性能。结论严格限定为“动作容量存在”。
