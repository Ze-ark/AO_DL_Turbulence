# 离线观测桥接：先让模型看懂正确的相位

2026-10-05 后续状态：O1 已实现并完成小型人工技术验证，见 [O1 技术记录](观测桥接O1技术验证记录.md)。下文“尚未实现”等为 O0 预检时的历史快照；O0 设计 JSON 不回写，真实标定未知量不填默认值。

结论：已有真实复光场 HDF5（分层数据文件），但不能直接接入 RL（强化学习）闭环。本轮完成 O0（观测接口预检）；下一最小任务是 O1（用已知答案的人工光场验证“相位图→21 个残余相位系数”），不用 SLM（空间光调制器），不重新训练。

## 1. 小白版：现在要解决什么

此前模型看到的是仿真器已经算好的 21 个相位系数。以后相机和 MATLAB 给的是强度图、相位图；必须先确认这两种表达说的是同一件事，包括左右方向、正负号、单位和测量时刻。

相位图的数值还会在 ±π 处折返，像角度从 179° 跳到 −179°。直接把这种图当作连续相位算系数，可能得到错误答案。本轮一个小型人工例子已说明这个风险，不能把它当成真实数据精度或 RL 性能结论。

因此，先用自己知道正确答案的人工光场检验转换，再准备全息观测仿真。当前不需要加训 RL，也不必立即重训 ResUNet（残差编码器—解码器网络）。

## 3. 接口对应关系

列区间均为 Python 左闭右开；沿用现有 79 维接口，不修改公共格式。

| 策略历史字段 | 应从哪里得到 | 当前真实 HDF5 是否足够 |
|---|---|---|
| 当前残余相位系数 `[0:21]` | 已标定的测量面/瞳面相位，经参考处理、方向和单位核对，再投影到冻结的 21 模态基 | 不足：尚缺光瞳、参考、方向、测量平面等标定 |
| 已发累计命令 `[21:42]` | 同步记录的控制器命令 | 没有；不能虚构为已执行的零命令 |
| 名义执行量估计 `[42:63]` | 已发命令加公开名义响应模型 | 缺命令日志；禁止替换为仿真隐藏实际动作 |
| 上一次修正 `[63:74]` | 控制器自己保存的 11 维修正 | 没有真实控制日志 |
| 已到达功率 `[74:75]` | 独立功率测量及预先标定的归一化 | 没有；不能用图像均值或总亮度代替 |
| 步号与功率归属 `[75:79]` | 同步时钟、命令索引、功率到达索引和有效标志 | 只有图片编号，不是采集时间戳 |

`ResidualGRUPolicy` 内部还会用“残余系数减名义执行量估计”构造伪开环特征。桥接层必须交付**残余**，不能事先做一次该变换后让策略再次减掉动作。

真实文件没有 `/target`、动作、时间戳或功率字段。每个温差组内帧号递增，但不同组会重新从 1 开始；不能把组首帧接到上一组历史，也不能据编号就设成仿真的 10 毫秒间隔。温差组只是来源分组，不是已经验证的完整控制 `episode`（回合）。

## 4. 必须先核对的四类风险

1. **坐标与正负号。** 图像从 256×256 变成 64×64，不代表相机和仿真光瞳已经对齐。需要光瞳位置、尺度、旋转、翻转、相位符号和测量平面；用非方形、非对称已知图案核验 MATLAB/HDF5 的行列方向。现有方形图的尺寸不能排除转置。`meta/crop_rect` 在 h5py 中实际为 `[4,N]`，不能误读成 `[N,4]`。
2. **相位参考与折返。** 当前导出器保存 `angle(field)`，属于包裹相位。不得直接对它做线性模态投影；解包裹或圆周相位拟合方案要先经过已知答案测试。参考相位及全局常量相位处理必须明确，不能随意删除策略需要的倾斜模态，也不能改冻结模态基。
3. **功率和时间。** 没有同步测量就标记缺失，不能把缺失说成真实的零功率或零动作。现有接口支持缺失功率标志，但这不证明冻结策略已适应长期缺测。没有控制动作反馈的离线播放不能用来宣称补偿收益。
4. **裁剪的因果性与来源。** 当前 MATLAB 导出器默认用同组前 5 帧估计频域裁剪窗口；实时实现须改用事前标定窗口或明确的初始化前缀，不可偷看未来帧。现有 HDF5 只记窗口，未记裁剪模式和导出代码版本，故本轮只指出实现风险，**不认定历史数据已发生泄漏**。原导出器会删除同名旧目标，不能对现有路径直接重跑。

## 5. 下一最小实验：O1 已知答案往返检查

研究问题：在明确坐标、相位参考和有效光瞳的人工复光场上，新观测转换是否能找回与冻结控制器一致的 21 个相位系数，并拒绝不能可靠解释的输入？这是软件单元验证，不是 RL 排名或真实精度测试。

状态：**设计已记录，桥接模块与新测试尚未实现；本轮没有新的正式运行命令。** 设计材料见 `configs/experiments/observation_bridge_design_v1.json`；这是预检/设计记录，不是可执行实验配置。真正实现时新增执行 YAML、独立模块和测试，不修改封存源码。

固定技术范围：

- 只引用 `build_action_basis` 构造与冻结模拟一致的 64×64、21 模态基、光瞳半径比例 0.4；这些是仿真约定，**不是实际相机标定值**。
- 小型确定性人工测试使用显式种子 831001，允许 CPU；不生成完整动态性能实验、训练更新或真实硬件动作。
- 对照是已知系数合成的复光场/相位，不读取 G2-C1 天气或确认轨迹。
- 首先验证读出方向、已知正负模态脉冲、复场共轭符号和不折返相位往返；再测试空间采样足够、连续且光瞳连通的跨 ±π 人工相位。
- 相位参考、低强度区域、缺失值与坐标未知必须显式处理。空间相位变化不可辨识、孔洞或标定未知时应拒绝，不承诺任何相位图都能唯一恢复。
- 无噪声受控单元例子的拟定最大系数误差门槛为 `1e-5 rad`；这是**待实施的技术容差**，不是已达到的真实数据精度。
- 接口测试需保证温差/回合切换清空历史、未来信息不进入当前输入、功率时钟不伪造；实际动作仍与请求动作区分。

拟定输出是新模块、确定性测试和一份技术验证记录；不产生新策略权重。坐标、符号、单位、参考或因果检查失败时停在该层，不进入新 RL 训练。
