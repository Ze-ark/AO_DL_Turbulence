# S4-D2-R2 高阶观测可学习性诊断计划

## 先说结论

高阶容量实验已经证明：新增11个高阶方向里存在能让补偿变好的动作。现在先不继续训练强化学习，而是做一次更容易解释的监督学习诊断，回答一个关键问题：旧SAC当时看到的4帧观测里，究竟有没有足够信息推断这些正确动作。

这一步会让“知道仿真答案的教师”产生标准答案，再让一个普通神经网络只根据旧SAC能够看到的信息学习答案。它不是强化学习，也不会操作真实SLM。

## 小白版原理

可以把这一步想成一次“开卷老师教闭卷学生”的考试：

- 教师能看到未来2帧的仿真真值和精确配准，所以知道新增11个旋钮应当怎么调；
- 学生看不到答案，只能看到旧SAC原本拥有的最近4帧记录；
- 学生只负责新增11维，前10维仍由冻结的传统控制器负责；
- 最后把学生放回动态闭环，看它是否真的提高桶内功率，而不只是在数据表上拟合得好。

如果学生学得会，说明旧SAC失败更可能与奖励太难、探索或训练优化有关；如果学生连标准答案都学不会，说明应先改善观测、时间记忆或状态表示，而不是盲目更换强化学习算法。

## 为何先做监督学习

强化学习失败可能同时混有三个原因：看不清状态、奖励信号太绕、训练不稳定。监督学习直接提供每一步的正确动作，因此先去掉奖励探索和信用分配的影响。这样得到的结论比直接把SAC换成TD3或PPO更容易解释。

## 正式设计

| 项目 | 设置 |
|---|---|
| 动作表示 | 总表示21维；学生只输出第11维以后的新增11维 |
| 前10维 | 冻结10维跟踪泄漏积分器，不由学生修改 |
| 教师 | 固定预见未来2帧，只为生成训练标签使用 |
| 学生输入 | 与旧SAC相同的4帧可部署状态，共210个数 |
| 学生不可见信息 | 未来真值、理想质量指标、硬件档位编号和精确配准参数 |
| 简单对照 | 岭回归，用于判断线性模型能否学习 |
| 神经网络 | 两层多层感知机，隐藏层256，输出11维，3个初始化种子 |
| 数据拆分 | 训练、验证、诊断测试按完整回合隔离 |
| 正式样本 | 训练115200、验证57600、诊断测试57600 |
| 硬件误差 | 6个纯仿真档位 |
| 动态条件 | 冻结流、带沸腾定风、带沸腾变风与噪声 |

诊断测试集只在模型和训练停止点冻结后使用，不参与调参。训练过程使用CUDA；CUDA不可用时立即停止，不会回退到CPU。

## 两层检查

第一层检查“动作有没有学像”：

1. 相比总输出零动作，动作均方误差技能分数至少为0.30；
2. 预测动作与教师动作的平均方向相似度至少为0.30；
3. 三个神经网络初始化种子都必须通过。

第二层检查“放回闭环有没有真改善”：

1. 桶内功率相对冻结传统基线至少提高2%；
2. 桶内功率和Strehl增量的95%置信区间下界大于0；
3. 残差相位均方根误差变化的95%置信区间上界小于0；
4. 违规率不超过5%；
5. 六个硬件误差档位全部通过；
6. 三个神经网络初始化种子都必须通过。

固定2帧教师自身也必须通过同一闭环门槛，否则本次诊断无效。

## 结果怎么解释

| 正式结果 | 含义与下一步 |
|---|---|
| 教师正对照失败 | 停止解释，先检查实验配置或实现 |
| 三个学生离线和闭环都通过 | 4帧观测基本够用；再设计只输出新增11维的RL，并重点修奖励、探索和优化 |
| 离线通过、闭环失败 | 单步预测尚可，但误差在闭环中累积；优先研究序列模型、闭环模仿或数据分布偏移 |
| 离线也失败 | 当前观测或简单模型不足；先改善时间记忆或空间特征，不继续堆SAC训练量 |

即使监督模型通过，也只允许先审计结果；不会自动授权新RL训练、S4-D3或真实SLM实验。

## 用户在IDE运行

请在仓库根目录的IDE集成终端运行一次正式训练：

```powershell
.\.venv\Scripts\python.exe scripts\train_s4_high_order_learnability.py --config configs\experiments\s4_high_order_learnability_v1.yaml
```

运行时会依次显示数据生成、三个初始化种子的训练和闭环诊断进度，并显示当前优化步、平均误差、预计剩余时间和CUDA显存；机器可读进度同时写入`progress.jsonl`。

正式输出目录是`outputs/s4_high_order_learnability_v1`。目录一旦存在，程序不会自动覆盖。若中途报错，请保留目录、日志和原始报错，不要删除后自行重跑。

## 主要输出

- `summary.json`：教师、岭回归、三个神经网络及最终解释；
- `teacher_dataset.pt`：按完整回合生成的监督数据；
- `checkpoints/`：岭回归与三个初始化种子的模型；
- `training_records.csv`：训练和验证误差；
- `scenario_records.csv`、`episode_records.csv`：闭环科学指标；
- `progress.jsonl`：实时机器可读进度；
- `preflight.json`、`effective_config.json`、`source_manifest.json`：复现与完整性证据。

训练完成后告诉助手：`高阶观测可学习性训练完成`。助手会先只读审计结果，再决定下一步，不会自动启动强化学习。
