## 先说结论

[G1 复核](S4-D2-R5-G1跨条件复核审计记录.md)的风速臂达标、硬件档位臂未达标，但两臂用了不同天气，不能直接相减。[G1-D1 开发诊断](S4-D2-R5-G1-D1新硬件档位配对诊断审计记录.md)又发现，在另一批天气中“全标称六槽位”本身也低于 `1%`，而六个新档位作为一组并未使平均优势下降。下一步用**同一批全新天气**把风速和档位集合同时放进四格对照，判断哪种改变、或两者叠加，影响策略相对积分器的收益。这仍是开发诊断，不给 G1 改判。

## 固定四格设计

| | 原六档 R5 合成硬件误差 | G1 六个新合成硬件档位 |
|---|---|---|
| 原风速 | A：共同参照 | B：只换档位集合 |
| 原风速 ×1.10 | C：只加快风速 | D：同时换两项 |

- 每格都用相同的全新天气 `6,700,000 + 10×i`（暂定 `i=0…23`），三类原湍流、完整 `200` 帧回合、三份 R5-2-v4 冻结权重、统一 `1.75` 倍策略动作及冻结积分器 `gain=0.15, leak=0.10`。
- 原六档与新六档均全部保留，不从 G1/G1-D1 的结果挑单个“容易过线”的档位。对应的**列表槽位**使用相同湍流、传感和功率随机流；槽位对齐是配对技术，不能把两个不同档位解释为“同一硬件只改了一个参数”。
- 四格仅改变风速因子与档位集合因子；观测接口、动作限制、模型、控制器参数、回合长度和评价方法保持一致。
- 快速冒烟另用 `6,710,000`，只检查软件与 CUDA，不用于科学结论。正式与冒烟、G1、G1-D1、R3 及训练随机流必须分离。

四格计划共有 `6912` 条“条件×控制器×天气×湍流×槽位”的分组记录和 `1,382,400` 次物理转移。正式运行前要检查每类湍流在 `200` 帧内的最大平移低于 `256` 像素相位屏边长，避免屏幕重复。

## 事前分析，不设新过线门槛

先在每格计算同条件配对的 `策略桶内功率 − 积分器桶内功率`，再计算三项：

1. **风速效应**：`(C−A 与 D−B) 的平均`；
2. **档位集合效应**：`(B−A 与 D−C) 的平均`；
3. **交互效应**：`(D−C)−(B−A)`，也等于 `(D−B)−(C−A)`；它回答“加快风速时，换档位集合的影响是否与原风速不同”。

这些减法均作用在“策略相对积分器的**绝对桶内功率增量**”上，不直接拿不同天气的百分比相减。每格还要单列积分器功率、策略功率、相对收益、Strehl 指标及其相对积分器的差值、残差相位均方根误差、违规/饱和/变化率受限比例、归一化动作裁剪率、请求—实际动作差距、模型前向耗时和失败回合数。按**完整天气**做配对重采样；湍流类别、档位和三份模型是分组，不是可虚增的独立天气样本。四格与分组结果全部保留，置信区间为探索性，未作多重比较校正时不能称确认显著。

本步**不设置新的 `1%` PASS/FAIL**，不借用 G1/G1-D1 天气调倍率或模型，也不将本开发结果拼入 R3/G1 确认集。即使某格超过 `1%`，也只是提出下一步假设；若要改进策略，需在其他开发天气实现和筛选，再到全新、事前封存的确认天气验证。
