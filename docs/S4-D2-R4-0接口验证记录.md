## 时间对齐

本环境的顺序为：

```text
第t帧历史 → 请求动作t → 执行器响应 → 本次动作功率p_t
→ 湍流推进 → 第t+1帧残余观测
```

学习目标是“下一帧残余观测 + 本次动作功率”。不能用下一帧观测附带的功率代替本次动作功率。本次二者最大绝对差为0.01581952，验证了这不是可忽略的字段命名差异；该数值不是算法增益。

迟到功率只更新已到达测量历史，不能冒充当前动作标签；缺失标签带无效掩码。回合重置清空历史、命令队列、功率和执行器估计。重复命令、未来测量及非有限值会报错停止；这不等于已经实现真实设备上的自动安全回退。
