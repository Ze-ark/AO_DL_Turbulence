# S4-D2-R3-D2-A8 分类与收益分离输出审计记录

## 结论

A8 的六次监督拟合和新独立测试均完整，末端报错只影响汇总元数据，已经通过只补写元数据的方式恢复。正式结论为 `HEAD_SPLIT_BENEFIT_NOT_CONFIRMED`：把“动作好坏”和“收益大小”改成两个末端输出，只在策略种子 9301 上显示配对收益，9302 与 9303 均未通过。

这不是强化学习训练，也不能说明强化学习已经可用。当前仍不允许完整强化学习重训、S4-D3 或真实 SLM 动作。

## A8 回答了什么

A8 固定 384 条训练回合、48 条验证回合、10000 批训练预算和相同初始化，只改变最后的输出方式：

- `shared`：同一个标量同时表示收益大小和动作好坏；
- `split`：共享前面的特征提取部分，但最后用两个输出分别处理收益大小与动作好坏。

六个模型全部完成 10000 批。所有模型冻结后才生成 96 条新的测试回合，共 324 条测试分支；测试数据没有参与训练或选检查点。

## 下一研究问题

A8 只把最后一层拆开，前面的两层特征提取网络仍然共享。因此 A8 失败有两种主要解释：

1. 最后一层分开仍不够，两个目标在共享特征提取部分继续互相干扰；
2. 并不存在稳定的共享主干冲突，问题更可能来自跨策略种子的标签分布、特征不足或泛化差异。

下一步 A8-D1 只读计算两个损失在共享主干上的梯度方向，不重新训练，也不读取 A8 独立测试集。它是失败机制诊断，不是新算法性能实验。

## 证据边界

- A8 是静态监督探针，不是动态强化学习；
- 9301 的局部阳性结果不能覆盖 9302 与 9303；
- A8 的测试结果已经揭盲，A8-D1 属于事后解释性诊断，不能单独证明因果关系；
- 只有后续预先注册的新实验才能验证“完全分离主干”是否真正改善泛化。
