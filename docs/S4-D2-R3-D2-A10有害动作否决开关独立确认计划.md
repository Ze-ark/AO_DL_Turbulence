# A10：让模型学会“不该动时就不动”

## 小白版说明

A9说明当前演员给出的动作多数会让16步累计奖励变差。下一步不让模型重新发明动作，而是给演员加一个安全开关：

```text
模型认为演员动作有利 → 使用演员动作
模型认为演员动作有害 → 使用零残差动作
```

这类似给原控制器加“否决按钮”。它仍不是完整强化学习训练，也不是连续闭环部署；它先检查现有模型能不能可靠识别明显有害的动作。

## 固定输入与防止偷看

- 冻结A9的9份“只学收益、由模型选择集选出”的模型：3个演员策略×3个初始化。通过A9摘要、训练冻结清单和模型哈希定位，不重新选择模型。
- A9训练集、选择集及两套确认集只能用于追溯和提出A10问题，不参与A10主结果。
- A10在设计冻结后生成两套全新天气回合；同一策略、三模型初始化和三个候选方法共享回合。
- 每个状态先由三份冻结模型分别预测演员动作相对零动作的16步奖励差；主开关使用三者原奖励单位预测的算术平均，大于0才放行演员动作。单模型结果仅作辅助。
- 预测阈值固定为0，不根据A10结果调节；不训练、不早停、不更新演员、评论家或学生。

## 三个公平对照

对相同状态同时计算：

1. 始终零动作：保守基线；
2. 始终演员动作：原冻结演员候选；
3. 否决开关：预测平均奖励差大于0时用演员动作，否则用零动作。

所有比较共享状态、天气、硬件误差、动作约束和16步分支。开关结果直接由同一零/演员配对构造，不插值或生成不存在的动作。

## 主要判定

主判定只使用同条件新回合。每个策略固定三项，共9项：

- 开关相对零动作的16步累计奖励增益；
- 开关相对零动作的桶内功率增益；
- 开关相对始终演员动作的16步累计奖励改善。

以完整天气回合为统计单位，按三种湍流分层配对重采样20000次；9项使用Bonferroni家族校正，总错误率0.05。三份初始化先形成一个冻结集成开关，不把初始化当独立天气样本。

一个策略只有三项校正区间下界都大于0，且每种湍流条件的奖励和功率点估计都不为负，才记为通过。至少2/3策略通过，A10才记录 `VETO_GATE_INDEPENDENT_CONFIRMATION_PASS`。否则为 `FAIL`，不因“比始终演员少坏很多”而忽略它仍可能不如零动作。

变化风况使用完全相同规则作预先声明的稳健性结果，但不替代主判定。还要报告放行动作比例、约束违规率和六个硬件误差档位；类别过少或零放行须保留并明确解释。

## 解释边界与停止规则

- 这是单次动作的16步反事实分支确认，不是开关连续运行后的闭环轨迹。
- 通过只说明该开关值得进入纯仿真闭环测试，不说明强化学习优于传统控制。
- 失败则关闭当前冻结评论家/否决路线，下一步重新设计算法，不自动增加训练量、改阈值或换确认集追求通过。
