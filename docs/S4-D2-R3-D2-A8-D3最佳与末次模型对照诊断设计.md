# S4-D2-R3-D2-A8-D3 最佳与末次模型对照诊断设计

## 小白版：这一步做什么

拿同一次训练留下来的两个模型版本做比较：一个是验证成绩最好的版本，一个是训练到最后的版本。让它们回答同一批旧题，查看两个学习目标的拉扯是否变化，以及训练题和验证题上的表现怎样变化。

这一步不训练，也不增加新题。它能检查问题是否与模型版本有关；不能凭两个时点判断问题第一次出现在哪一批，更不能直接证明换强化学习算法就能解决。

本设计在 2026-09-04 开始实现前冻结；下列阈值写入配置并校验，不能根据新梯度结果调整。实现、测试与正式命令的状态另记在准备验证记录中；不要重跑 A8 或 A8-D2。

## 研究问题与已知信息

主要问题：A8-D2 观察到的训练—验证梯度缺口，在最佳与末次检查点之间是否有稳定、实际明显的变化？

辅助问题：固定检查点在完整训练/验证数据上的分类、收益估计与梯度大小是否呈现分化？

设计类型为事后、配对检查点诊断。A8-D1/D2 和 A8 的验证日志已经看过；本分析不是独立泛化确认。资源依据见 [清点记录](S4-D2-R3-D2-A8-D3检查点与日志清点记录.md)，A8-D2 结论见 [审计记录](S4-D2-R3-D2-A8-D2训练验证梯度翻转来源诊断审计记录.md)。

## 固定对照

| 维度 | 固定内容 |
|---|---|
| 随机种子 | 9301、9302、9303，不能只选失败或有利的种子 |
| 模型结构 | 共享输出、分离输出；隐藏层宽度 256 |
| 模型版本 | 原 `checkpoint_best.pt` 和原 `checkpoint_last.pt` |
| 数据 | 每个种子 384 个训练回合、48 个验证回合；每回合 18 个动作配对 |
| 输入与目标 | 221维输入、16步累计奖励目标；沿用原数据、归一化与类别权重 |
| 损失 | Huber 收益损失，参数 1.0；训练集加权二分类损失，混合权重 0.25 |
| 禁止改变 | 权重、动作范围、模型结构、奖励、数据拆分、测试集和原性能门槛 |

最佳版本的批次分别为：共享输出 2300、1100、1500；分离输出 200、3900、4600。末次版本均为 10000 批。不同种子间最佳时点不一致，不得把它们当成统一训练时刻。

## 输入与对齐门槛

1. 固定 A8 的 `training_fits.json`、训练冻结标记，以及其中六对检查点、六份历史日志和六份进度日志的原始哈希。
2. 固定 A8-D1 的逐回合梯度、摘要和成功标记；固定 A8-D2 的摘要、成功标记及本次审计记录。
3. 训练/验证数据只使用 `outputs/s4_r3_h16_data_scaling_v1/datasets/seed_种子_large_pairs.pt` 与 `seed_种子_validation_pairs.pt`，沿用 A8-D1 中已经固定的六个哈希。
4. 检查最佳/末次元数据中的种子、结构、时域、输入维度与更新批次；归一化参数必须一致，不能分别用验证集重新计算尺度。
5. 先复算全部最佳模型的 2592 条逐回合梯度，与 A8-D1 的同键记录比较。连续量采用 `atol=1e-6, rtol=1e-5`；键、数量、每回合配对数、冲突符号须一致。超差时停止，不能放宽容差后继续。
6. 预测读数与原最佳训练/验证指标、原末次验证日志对齐；平衡准确率绝对误差不超过 `1e-6`，收益误差沿用上述连续量容差。此步骤用于排查实现差异，不是重新选择最佳模型。

若出现数据、代码或模型不一致，记录 `ALIGNMENT_FAILED`，停止并请求审查，不自动修复或重训。

## 计算内容

### 1. 完整回合梯度

在 `eval()` 模式下，用与 A8-D1 一致的前两层共享参数、损失和 `torch.autograd.grad` 计算方向；不调用优化器，不执行参数更新，不往参数 `.grad` 累积梯度。

三个种子 × 两种结构 × 两种模型版本 × (384+48) 个回合，共 **5184 条逐回合梯度记录**。逐层余弦、梯度范数、相对大小和冲突比例用于辅助描述，零梯度或非有限数值立即报错，不静默跳过样本。

### 2. 完整数据预测指标

在同一固定模型上重新计算完整训练集和验证集，形成 **24 组指标**：

- 分类平衡准确率、马修斯相关系数（MCC）、类别数量；
- 奖励差平均绝对误差、按奖励数值正负判断动作的平衡准确率；
- 分离输出的两个判断是否一致；
- 完整数据的收益损失、分类损失和按原权重合成的损失。

分类指标用所有配对的混淆计数汇总，不能简单平均可能缺类的逐回合准确率。训练指标与验证指标必须同定义、同单位；日志中的混合小批损失只作背景，不代替本次计算。

## 主要统计比较

对每个“种子×结构”，定义一个模型版本的缺口：

`G = 验证回合平均梯度余弦 - 训练回合平均梯度余弦`。

主要比较是：`ΔG = G末次 - G最佳`。共有六个主要比较。

- 同一回合的最佳/末次结果先作差，保留配对关系；
- 训练回合与验证回合互不配对，在各湍流条件内部独立重采样；
- 固定重采样 20000 次，基础种子 890000；配置需给六项分配不同且固定的随机数流；
- 报告普通95%区间和六项 Bonferroni 家族校正区间，家族总错误率 0.05；
- 实际明显变化门槛为余弦缺口变化 0.20。

### 固定的判定

某种子的 `ΔG` 校正区间全部大于 +0.20，或全部小于 -0.20，才算明显的检查点敏感性。

至少两个共享输出种子同时满足且方向一致，才记为 `CHECKPOINT_SENSITIVE_GAP_CANDIDATE`（模型版本敏感性候选）；否则记为 `CHECKPOINT_SENSITIVITY_NOT_CONFIRMED`。三个种子和两种结构的全部结果都要保留，不只报告通过项。

另报告每个版本自身的 G 和三个条件内读数；分离输出作为结构对照，但不根据事后看见的差异新增显著性门槛。

预测性能与完整数据损失先作描述性辅助结果，不用于宣称“多任务过拟合已证实”。原最佳版本经过验证选择，而且本次没有独立测试、单任务训练对照或完整中间模型序列。

## 结果可以与不可以说明什么

- 若版本敏感性得到支持：说明固定检查点的选择/训练进程与梯度缺口有关；仍不能区分选择偏差、训练时长、优化过程等原因。
- 若没有得到支持：说明这两个时点不足以支持敏感性；不能据此证明梯度在所有训练时刻都一样。
- 即使看到训练表现改善、验证表现下降，也只记录“训练—验证分化候选”；不能只凭被选择过的最佳版本与末次版本作过拟合因果判断。
- 若以后需要确认首次翻转时刻或多任务特异性，必须另行设计固定时刻留档或单任务对照，并先获得用户同意；本阶段不自动安排重训。
