## 1. 先说结论

可以先进行纯仿真，再迁移到实际实验，而且这是当前最稳妥的路线。

```text
纯仿真练习 → 模拟真实硬件缺点 → 冻结控制器
→ 真实系统只计算不执行 → 小幅双 SLM 实验 → 独立物理扰动
```

但“先仿真”不等于立刻训练 RL。正确顺序是：

1. 先把光传播仿真修正确；
2. 建立动作会影响下一帧的动态闭环；
3. 先完成强传统控制器；
4. 再判断 RL 是否带来额外价值；
5. 最后把 H1 测到的 SLM 误差加入仿真并迁移。

## 2. 把系统想成一个连续游戏

大气湍流不断改变光束。控制器每一步需要：

```mermaid
flowchart LR
    A["测量当前复光场"] --> B["计算补偿动作"]
    B --> C["SLM-B 显示补偿相位"]
    C --> D["光场继续传播"]
    D --> E["相机和功率计测量结果"]
    E --> A
```

真正的 RL 数据必须包含：

```text
当前观测 → 实际动作 → 奖励 → 下一观测
```

当前项目里的静态图片和复光场没有“动作造成的下一观测”，因此现有 ResUNet 更像一次性看图答题，不是闭环 RL。

## 3. 当前项目已经有什么

- MATLAB 湍流传播和 HDF5 导出代码；
- 输入光强和相位、输出补偿相位的 ResUNet；
- 11 个温差组的真实离轴全息复光场；
- GPU-only 的 PyTorch 训练与评估入口；
- 两台中科微星 `FSLM-2K73-P04` 相位型反射式 SLM；
- 光功率计。

这些资产可以继续使用，但当前诚实状态是：

> 已有静态监督学习原型和真实复光场推理，尚未建立动态 RL 环境，也尚未完成真实闭环补偿。

## 4. 两条路线并行推进

### 电脑端

```text
S0 修复物理仿真
→ S1 动态闭环环境
→ S2 传统控制基线
→ S3 RL 先导比较
→ S4 硬件化仿真
→ S5 仿真到真实迁移
```

### 实验室端

```text
H0 设备建档
→ H1 两台 SLM 分别标定
→ H2 不用 RL 的静态闭环
→ H3 动作—响应与时序辨识
```

电脑端 S0—S3 不需要等待完整光路。实验室 H1 得到的相位范围、LUT、稳定时间、量化和配准误差，会在 S4 中替换假设参数。

## 5. 纯仿真具体做什么

### S0：先把练习场建正确

S0 已完成以下修复：

- 相位屏必须在正确的空间域使用；
- 第一块相位屏不能跳过；
- 无湍流参考场必须传播到同一接收面；
- `r0` 必须按完整传播路径计算；
- 补偿动作必须真的改变焦平面或接收面指标；
- 测试场景不能参与训练或选模。

S0 MATLAB 测试已全部通过，详细记录见 [S0 物理门验证记录](S0物理门验证记录.md)。

### S1：建立动态环境

状态：`S1 核心环境已于 2026-08-03 通过验证`。

每个回合模拟连续变化的湍流，而不是随机抽取互不相关的图片。首轮观测使用低维特征：

- 少量可控相位模态；
- 光强或闪烁特征；
- 前几步实际动作；
- 延迟和有效帧标记。

首轮动作使用低阶模态增量，不直接控制 2048 × 2048 个像素。

当前已经实现严格泰勒冻结流、可选沸腾项、十个低阶模态、SLM 延迟/量化/饱和、焦面奖励和 GPU 批量运行。S1 的低维真值观测和 S2 的二维理想瞳面观测已经分开，避免把仿真答案偷偷泄漏给 ResUNet。

### S2：先把传统方法做好

状态：`已于 2026-08-03 通过最终纯仿真门槛，并完成确定性复现`。

至少比较：

1. 条件成立时的直接相位补偿或受约束投影；
2. 调优后的泄漏积分器；
3. 线性预测、LQG 或 MPC；
4. 统一观测下的动态无记忆 ResUNet；
5. 模态子空间内的理想上限。

如果传统基线还没有稳定工作，不能用弱基线衬托 RL。

本轮结果是：以桶内功率为主要指标，泄漏积分器最好；ResUNet 有明显补偿效果，但没有超过传统控制器。这是有效的负结果，不需要为了“必须用深度学习”而忽略它。

### S3：再测试 RL

第一步不是马上训练 RL，而是先看使用多帧历史的非线性模型能否稳定超过线性预测器。只有这个条件成立，才继续比较模型预测控制和 RL。

算法按证据选择：

```text
没有时间规律
    → 不做 RL

线性模型已经足够
    → 使用 LQG 或 MPC

非线性模型稳定优于线性模型
    → 比较“同一模型 + MPC”和“同一模型 + PO4AO 式策略”

需要另一条 RL 对照
    → 残差 SAC

PPO
    → 先只做纯仿真补充
```

RL 的动作必须经过硬限制，包括总相位、单步变化、模态范围、空间梯度、量化和饱和。

### S4：把仿真变得像真实设备

加入：

- SLM 60 Hz 标称刷新和实测稳定时间；
- 灰度—相位 LUT 偏差；
- 8 位或 10 位实际量化；
- 相位范围、饱和和迟滞；
- 相机曝光、噪声、丢帧和重建失败；
- 坐标旋转、缩放、平移和漂移；
- 光功率计采样噪声；
- 0—3 帧控制延迟。

未知参数先在保守范围内随机变化，H1 完成后改成实测分布。

## 6. 怎样从仿真迁移到双 SLM

迁移时固定顺序：

1. 在仿真中冻结算法、模型和动作范围；
2. 用真实相机数据做影子运行，只计算动作，不发送到 SLM；
3. 检查动作是否越界、饱和或频繁触发回退；
4. SLM-A 播放对控制器隐藏的安全扰动；
5. SLM-B 只执行很小的补偿增量；
6. 经典控制器或最后一个安全图案随时接管；
7. 仿真与双 SLM 结果稳定后，再加入热空气或相位板等独立物理扰动。

首轮真实系统不允许 RL 自由在线试错。

## 7. 奖励和主要评价

训练奖励可以写成：

```text
奖励 = 相位改善 + 焦点改善 - 动作变化代价 - 饱和与违规代价
```

但论文主要指标必须与奖励分开，优先选择：

- 时间平均归一化焦点功率；
- Strehl 或环围能量；
- 光纤耦合效率；
- 瞳面残余相位均方根。

光功率计必须放在聚焦透镜和小孔、单模光纤或小光阑之后。整束总功率不能作为相位补偿成功的主要指标。

## 8. 怎样判断 RL 值不值得继续

继续条件：

- 在封存扰动上稳定超过最强可部署传统基线；
- 改进大于重复测量噪声和预先规定的最小有意义差异；
- 对未见风速、延迟、噪声和 SLM 失配仍有效；
- 没有增加违规、失败和回退率；
- 打乱时间或删除动作历史后，优势明显下降。

停止或转向条件：

- 非线性模型不能超过线性预测；
- RL 优势小于测量波动；
- MPC 表现相同但更快、更稳定；
- 优势只存在于训练扰动；
- SLM 速度不足以支持有意义的动态闭环。

负结果不是失败。它可以证明在完整复场观测下，简单控制已经足够，RL 没有必要。
