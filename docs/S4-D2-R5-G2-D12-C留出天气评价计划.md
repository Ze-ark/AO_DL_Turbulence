## 小白版：这次看什么

训练损失类似“做练习题的错误有多少”，不等于真正考试成绩。现在让模型在本折没参与训练的天气上做选择，再打开已有候选结果看它选得怎么样。

重点看：选的动作是否比旧动作好、是否比一个固定微调方向好、最近八帧是否比当前一帧的模型稳定，以及是否增加了违规情况。不会再训练，也不需要重新跑光学仿真。

## 固定来源、预算与折分

唯一输入来自 A 的 2,592 个因果配对状态及 B 的 24 份第 1,000 次末次权重，锁定 A/B 成功文件、代码、配置和检查点哈希。B 中间权重仅做保存完整性校验，不用于预测或挑选模型。

四个完整天气折，每折模型只评价该折两个留出天气、648 个状态，不允许借用其他见过该天气的折模型。天气的两硬件条件、所有时刻、冻结 D8 来源策略初始化、湍流类型和槽位保持同折。

正式：两模型 × 三个打分器训练种子 × 2,592 状态 = 15,552 次模型选择。每批 128，24 个检查点各六次前向，共 144 次网络调用。已有标签的五方法评分共 38,880 个状态—方法—种子项，只是重复查询已有标签，不是新增物理交互或独立样本。物理转移、梯度更新、真实 SLM 动作均为零。

技术冒烟仅使用 A/B 的旧技术集合：36 状态、两份两次更新的技术权重，批量 8，共十次前向、72 次模型选择。该集合与技术训练天气相同，**不具备留出评价意义**；`analysis={}`、天气/分组汇总为空。已经完成，不要重跑。

## 动作选择：先选择，后评分

模型输入保持 B 的 76 维因果特征、有效掩码及当时冻结策略命令；不接收天气、硬件档位、未来标签、真实相位或实际执行硬件状态。

预测原动作及等价裁剪动作分数固定为零，其余 23 候选沿用训练输出分数，取最大；同分优先原动作。负预测可回到原动作，但不得根据真实未来功率、安全标签或留出最优阈值决定回退。

三个训练种子分别选择动作并分别报告；预定总体结果是这些选择各自结果的平均，不是挑最好种子，不是平均预测后另做一个集成动作，也不是宣称一个已经部署的集成控制器。

标准化读取对应检查点，并在预检中与仅用本折训练天气重算的参数精确核对。固定方向也只能使用对应训练天气确定的索引。模型选择全部保存后，未来标签才用于本轮评分；预检中的标签访问只做来源/格式及训练方向审计，不能决定本轮模型选择。

## 五个比较对象

| 方法 | 如何决定动作 | 是否可作为合法选择方法 |
|---|---|---|
| 旧原动作 | 原冻结 D8 状态对应动作 | 是，作为零差值参照 |
| 训练固定方向 | 本折六个训练天气平均收益选定方向 | 是，不看留出答案 |
| 当前帧打分器 | 当前因果观测预测分数 | 是 |
| 八帧历史打分器 | 最近八帧因果观测预测分数 | 是 |
| 真值最佳候选 | 看完 25 候选未来功率后选最高 | 否，仅不可部署的乐观参照 |

“可作为合法选择方法”不等于硬件安全认证。这一步查询缓存标签，不执行任何新动作。候选集和安全投影仍是 R1 冻结版本，不扩大动作范围。

## 科学读数与统计规则

主读数是相对原冻结 D8 动作的**延迟后短窗口真值桶内功率差**，单位是原归一化功率的差值，不是百分比；独立报告同窗口测量功率差。这里不是“RL 相对积分器的完整回合增益”，不能拿它直接判定原 1.05% 开发门槛。

报告相对原动作及训练固定方向的两模型收益，历史减当前的配对差，收益正/负状态比例、相对最佳候选损失、预测功率差均方根误差。所有状态、条件和三个种子都保留，不挑结果好的部分。

安全读数沿用 A 三个最大比例：违规、饱和、变化速率。报告所选候选绝对最大值、相对原动作变化以及是否超过原最大值 +0.001。这个相对通过条件不代表绝对零违规，更不是正式硬件安全保证。即使候选未来不安全，也保留选择并如实计分，不能事后删掉。

先平均状态内三个训练种子的选择结果，再汇总每天气；也单独报告每个种子。两个条件各有八天气、每天气 162 状态，分别报告；按条件/湍流/槽位/时刻再列 108 个描述分组。

天气重采样种子 7565000，5,000 次，所有方法共享天气抽样，给出 95% 描述区间和正收益天气数。只有八天气，且交叉训练折重叠、没有重采样重新训练；这些区间条件于固定模型，不覆盖训练不确定性，不能当独立确认置信区间。没有正式假设检验或自动科学放行门槛，不依据哪个区间好看修改分析。

比例中重复的状态—种子项不当成独立样本。若最佳候选平均改善为零，捕获比例返回明确 `null` 原因，不用 NaN/Infinity，也不夸大“达到上限”。

## 保存与复核

- `predictions.pt`：每状态、模型、种子的原缩放预测和选择索引，用于审计；不是训练权重。
- `evaluation.pt`：五方法选择、真值/测量功率差、三个安全最大值/变化、相对安全标志、最佳候选损失。

- `manifest.json`：每个末次检查点哈希和对应评价索引、训练/留出天气。
- `weather_metrics.json`、`group_metrics.json`、`summary.json`：天气/分组描述、种子稳定性、校准误差和配对区间。
- `config.json`、`preflight.json`、`runtime.json`、`progress.jsonl`、`SUCCESS.json`；出错时留 `failure.json`，禁止覆盖原目录。

保存 GPU 批量推理均摊耗时，但它包含批量索引、标准化和网络前向，不是单帧硬件闭环延迟；首次调用初始化亦可能影响时间，不能据此比较完整控制系统速度。
