# 同状态动作力度诊断

当前结论：正式R1模型预测控制相对积分器的桶内功率增量为约0.446%，未达到原定1%门槛。下一步检查“同一状态，修正力度换一下会怎样”，不重新训练，不放宽安全约束。

## 要回答的问题

R1的动作已经经常非零，不能仅凭收益小就断言“没有动作”。本轮比较当前动作的0、0.5、1、1.5倍，检验局部力度敏感性。1.5倍先截到原来的归一化范围[-1,1]，再经过原安全投影；不是把物理动作范围扩大1.5倍。

只改变首步。之后7步，各分支都由同一个积分器根据各自新观测继续控制，高阶额外修正为零。这样检测的是“单次修正在随后8步的影响”，不是把四种策略重新跑200步，也不能直接推算全回合能提升多少。

- 在探测点复制完整环境、接口和随机数状态，四组从相同状态出发。原力度分支第一步必须重现原轨迹的功率和实际动作。

## 指标与分析

主指标是随后8步平均无噪声桶内功率；同时保存Strehl、违规像素比例、残差相位、测量功率、请求及实际动作、各模型预测。

预声明三个对比：1.5倍减原力度（主要问题）、半力度减原力度、原力度减零修正。先在天气内平均档位与探测时刻，按三类天气分层、以完整天气配对重采样20,000次。报告三个Bonferroni校正的98.333%区间，不能把帧当独立样本。保存按家族、档位分解的结果；不自动挑选最佳力度或据此通过RL门槛。

模型预测差与物理响应差仅作为后续只读校准分析，保留近零响应，不把符号接近零的分支随意过滤。测量功率是预测目标，无噪声功率是科学指标，二者分别报告。首步动作放大被截断的分量必须记录。

结果解释边界：放大改善只支持所选状态下的局部改善空间；放大无效不能单独证明模型错误，也可能受延迟、其他动作限制或探测窗口影响。单次脉冲不是重新搜索动作方向，更不是持续放大策略验证。
