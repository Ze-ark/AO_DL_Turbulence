## 解释边界

可以确认：

1. 现有6个SAC检查点在新诊断回合上稳定失败；
2. 21维失败在几乎没有投影时仍存在；
3. 36维投影冲突严重，但消除残差投影后仍失败；
4. 当前问题更接近“策略学到的模态组合具有破坏性”，而不是单一缩放或符号问题。

尚不能确认：

- 破坏主要来自前10个锚点模式，还是新增高阶模式；
- 是观测可辨识性不足、动作参数化不合适，还是SAC优化失败；
- 更换PPO、TD3或其他算法是否会改善。
