## 先说结论

D1-B已经发现：演员动作第一步的训练奖励更低，但目标评论家仍认为未来会补回来。D1-C
不训练新模型，只回答“评论家要看多少步，才会发现这个动作其实不好”。

程序比较以下六个时间长度：

```text
1步 → 2步 → 4步 → 8步 → 16步 → 32步
```

如果目标预测很快变成负数，说明短期一步学习不够；如果看到32步仍预测正数，说明目标
评论家的乐观偏差会长期持续，需要更保守的评论家方法，而不只是把一步改成两步。

## 用小白语言理解

评论家像是在预测一项投资未来能不能赚钱：

- 一步目标只看今天的实际收益，再让评论家估计以后；
- 四步目标先看四天真实收益，剩余部分才让评论家估计；
- 三十二步目标已经看了更长的真实过程，对评论家“猜未来”的依赖更小。

D1-C就是逐渐增加真实观察长度，看评论家的乐观判断在哪个时刻被事实纠正。

## 公平比较方式

每个探针只比较两个动作：

1. 零动作：冻结学生策略，不加RL修正；
2. 演员动作：第一步加入完整RL修正。

第一步之后，两条分支都继续使用同一个冻结的确定性演员。因此唯一差别仍是探针处的
第一个动作。每条分支只运行一次32步，在中途截取六个时域，不重复生成物理轨迹。

每个时域记录：

- 已经真实执行部分的累计训练奖励；
- 已经真实执行部分的累计真实桶内功率；
- 目标评论家对剩余未来的估值；
- “真实累计奖励 + 剩余估值”组成的多步目标；
- 在线Q相对多步目标高估多少。

本诊断使用确定性部署演员，不是精确的随机SAC软Q曲线。D1-B已经单独检查软目标和熵项，
D1-C专门定位确定性部署时的自举偏差长度。

## 预声明判定

所有置信区间按24条独立湍流轨迹聚类计算，三个学生主干种子必须一致：

- 1步预测乐观，32步目标仍显著为正，但真实32步回报为负：
  `PERSISTENT_BOOTSTRAP_OPTIMISM_CONFIRMED`；
- 1步预测乐观，但三个种子都在某个有限时域显著转为负：
  `BOOTSTRAP_OPTIMISM_WITH_FINITE_HORIZON_CORRECTION`；
- 1步乐观成立，但三个种子的转折时域不一致或区间跨0：
  `BOOTSTRAP_OPTIMISM_DECAYS_WITHOUT_UNIFORM_SIGN_FLIP`；
- 三个种子的初始机制不一致：保持混合结果。

结果不会自动授权重训、改算法或开放S4-D3。正式运行后必须先审计。
