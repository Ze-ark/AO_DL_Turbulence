## 先说结论

本阶段不是继续训练，而是给现有R3模型做一次“体检”。我们把六个已经训练好的模型
完全冻结，在新的仿真回合里改变它们的动作大小和方向，再看评论家打分、训练奖励和
真实补偿指标是否互相矛盾。

这个诊断不会让模型学习，不会写新检查点，不会改算法、奖励或通过门槛，也不会访问
S4-D3或真实SLM。它只能告诉我们下一轮应该修哪里，不能直接把R3的FAIL改成PASS。

## 小白版：五个要回答的问题

1. **方向错了吗？** 如果把RL动作反过来，效果反而更好，说明模型可能把方向学反了。
2. **动作太大了吗？** 如果25%或50%动作比100%动作好，说明方向可能有用，但下手太重。
3. **演员看懂了吗？** 把演员动作与有未来真值的理想教师动作比较，只用于诊断方向。
4. **评论家打错分了吗？** 看评论家是否给实际更差的动作更高分。
5. **奖励带偏了吗？** 看训练奖励说“变好”时，桶内功率是否实际下降。

## 比较的动作

| 诊断动作 | RL修正比例 | 用途 |
|---|---:|---|
| 完全反向 | -100% | 强检验动作方向是否相反 |
| 半幅反向 | -50% | 检查较温和的反向是否有帮助 |
| 只用学生 | 0% | 所有比较的主要基准 |
| 四分之一正向 | 25% | 检查是否只是动作过大 |
| 半幅正向 | 50% | 检查缩小后能否恢复 |
| 原始正向 | 100% | 复现冻结R3策略的行为 |

所有比例只缩放RL新增11维修正。传统控制器和冻结学生策略保持完全相同，零比例必须
与学生基准逐步对齐。

## 正式实验规模

```text
6个R3最佳检查点
× 6个硬件误差档位
× 3种新动态湍流条件
× 6种动作比例
= 648个配对场景

每个场景16个回合、每回合200步
= 10368条回合记录
```

诊断种子从`3700000`、`3710000`和`3720000`开始，与训练、验证和预留的
`4000000—4999999` S4-D3种子隔离。两个主干组、不同动作比例和学生基准在同一
物理回合上配对比较。

## 记录内容

每个场景至少保存：

- 桶内功率、斯特列尔比、残差相位均方根和违规率；
- 演员请求、实际施加修正、动作大小和安全投影比例；
- 演员动作与理想教师修正的余弦相似度、同方向比例和均方误差；
- 评论家对演员、零动作、反向动作和理想动作的评分；
- 旧训练奖励与真实桶内功率相对学生基准的变化；
- 零动作与学生基准的最大差异；
- 配置、输入、检查点和源码哈希。

理想教师允许读取未来真值，但只存在于诊断面板，不能进入策略观测、经验回放或训练。

## 解释规则

程序会给出预声明标签，并保留逐种子结果：

| 标签 | 小白解释 |
|---|---|
| `ACTION_DIRECTION_MISMATCH_SUPPORTED` | 反向动作稳定更好，支持方向学反 |
| `EXCESSIVE_ACTION_AMPLITUDE_SUPPORTED` | 缩小动作稳定更好，支持动作过大 |
| `CRITIC_RANKING_FAILURE_SUPPORTED` | 评论家更喜欢实际更差的动作 |
| `REWARD_METRIC_CONFLICT_SUPPORTED` | 训练奖励与真实桶内功率方向冲突 |
| `POLICY_TEACHER_DIRECTION_MISMATCH_SUPPORTED` | 演员与理想教师方向一致性过低 |
| `NO_TESTED_CORRECTION_IMPROVES_STUDENT` | 测试过的正向、反向和缩小动作都没超过学生 |
| `CAUSE_NOT_ISOLATED` | 现有面板还不能定位单一原因 |

如果不同策略种子给出不同结论，则标记为混合证据，不强行归结为单一原因。任何标签
都只用于决定下一次实验，不自动授权重训、换算法、改奖励或放宽门槛。
