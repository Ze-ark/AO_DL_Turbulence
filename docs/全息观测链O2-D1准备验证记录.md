# O2-D1 单因素读出噪声诊断：可以由用户启动

结论：**入口、35 项相关测试、9 次 CUDA 快速技术读取和正式静态源预检已通过。** 用户已选择先只增加读出噪声；现在可以在 IDE（开发环境）终端启动完整静态诊断。它不是训练，不运行控制器，也不操作真实相机或 SLM。

## 小白版：这一步干什么

给同一张人工全息图加不同程度的“雪花”，查看相位读数会偏多少、什么时候程序认为已经看不清。这只是为后续闭环压力测试建立标尺，**不是要求模型再次超过 1% 或 1.05%**。

同一档出现看不清的读数，也可能是本次压力诊断的正常记录。只有程序意外崩溃、来源或抽样不一致等才立即停止；不能把看不清的图改成真值。

## 实现与事前规则

| 文件 | 作用 |
|---|---|
| `observation_bridge/read_noise_diagnostic.py` | 新静态样本、固定噪声配对、有效性/误差统计、失败留痕和来源检查 |
| `scripts/diagnose_observation_bridge_o2_read_noise.py` | 用户 IDE 入口，支持正式、技术冒烟和只读预检 |
| `configs/experiments/observation_bridge_o2_d1_read_noise_v1.yaml` | 55 光场、16 次噪声重复、8 档标准差与零控制/零训练边界 |
| `tests/test_observation_bridge_o2_read_noise.py` | 小型元数据、几何、文件生命周期和 CUDA 技术单元 |

前瞻设计见 [D1 计划](全息观测链O2-D1读出噪声标尺诊断计划.md)。正式预算为 55 张固定完整光场、880 张独立标准正态噪声图和 7,040 次测量尝试；各噪声档共享同一次抽图，包括零噪声档。55 张干净干涉图各生成一次，不是 7,040 个独立天气。图像标准差均为任意合成强度单位，不是真实相机电子数、曝光或灰度标定。

有效性拒绝仅捕获原测量器的三种明确保护：低强度/孔洞、空间相位跳变、相位环路不一致；保留原原因并继续下一个事前列出的静态读取。零噪声拒绝、非有限值、设备/配置错误及其他异常不捕获为普通拒绝，立即保留失败现场并停止，不自动重试。

有效读数的误差统计与无效分母并列，不给无效读数插补零误差。测量器只接收当前重建复场；测量返回后才计算独立真值拟合目标，没有模型加载、策略前向或环境转移。16 次重复仅改变噪声，不改变源相位，不根据控制收益选择档位。
