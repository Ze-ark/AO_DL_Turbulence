# G2-D5 延迟功率梯度诊断审计记录

## 结论

在冻结策略的五帧仿真探针中，动作尚未到达仿真空间光调制器（SLM）时，光学功率对该动作的梯度为零；到达后梯度存在，并且多数情况下与实际量化前向的 ±5% 动作变化同向。因此，现有证据**不支持“跨帧梯度断开”或“量化代理梯度普遍反号”**作为 G2-D3 失败的主要解释。第一帧动作惩罚确实鼓励缩小动作，但这并不证明它是完整 200 帧训练结果的主因。G2-D3 的失败判定和原门槛均不变。

## 数值结果与解释边界

对可比的延迟后探针，直通估计器（STE）代理梯度与 ±5% 硬前向功率变化的径向方向一致率如下。分母是**局部探针数**，不是独立天气数：

| 仿真条件 | 1.0 倍训练臂 | 1.75 倍训练臂 |
|---|---:|---:|
| 标称同槽 | 556/647 = 85.94% | 583/648 = 89.97% |
| 新硬件档位 | 534/648 = 82.41% | 550/648 = 84.88% |

延迟前 11 维梯度和硬前向功率变化均为零；延迟后代理径向零记录为 0，硬前向径向零记录为 1。批量计算图的连通标记全为真，**不等于**证明每一个样本的梯度都非零，更不等于证明完整 200 帧的梯度有效。

第一帧训练评分的径向导数在标称/新硬件条件下分别为 `−0.002451/−0.002539`，正好是测量功率尚未响应时的动作与平滑惩罚。五帧物理功率径向导数的**总和**约为 `+0.003606/+0.003293`，大于这一次首帧惩罚；但训练实际每帧都重新发动作、每帧都计惩罚，并将完整 200 帧取均值。不能把五帧总和与未经同样时间聚合的惩罚混比，也不能从本探针推出“惩罚必然压过收益”。

同一结论与 [G2-D4 同状态诊断计划](S4-D2-R5-G2-D4同状态动作与延迟功率诊断准备.md)中的机制问题衔接，但不改判 [G2-D3 完整闭环开发评价](S4-D2-R5-G2-D3新天气配对闭环开发评价计划.md)：1.75 倍训练臂在两条件下的桶内功率均低于 1.0 倍训练臂，相对积分器增益约 `0.850%/0.859%`，未达到原 `1.05%` 开发继续条件。它们都只是仿真结果，不是自然大气或真实 SLM 结果。
