# O2-D1：先给“眼睛变模糊”建立一把标尺

结论：**先不训练，也不跑完整控制回合。** 只给人工全息图逐档加读出噪声，测量“图像噪声多大 → 相位读数偏差多大 → 是否还能重建”。完成这一步，再准备冻结控制器的闭环压力测试。

用户已明确选择“先做单因素读出噪声测试”。新入口、配置和相关技术验证已完成，正式诊断仍由用户在 IDE 启动；当前命令见 [准备验证记录](全息观测链O2-D1准备验证记录.md)。以下是运行前固定的合成诊断参数，不是真实设备规格；不悄悄加入光子噪声、曝光或其他相机参数。

## 1. 为什么要做

[O2-C 完成审计](全息观测链O2-C完成审计记录.md)显示，小噪声后的平均模态读数误差只有约 `0.000002 rad`，当前方法平均功率变化约 `4e-8`。它基本等于给很清晰的图像加一点点干扰，尚不能回答“明显不准的读数下还能不能控制”。

本轮只回答传感链问题，不评价哪种控制器更好。这里的“标尺”是**合成噪声与读数误差的对应表**，不是实验室相机标定。

## 2. 研究问题、变量与边界

- 研究问题：固定图像生成、重建及模态读取时，增加合成读出噪声会产生怎样的误差和失效曲线？
- 假设：噪声增强可能增加读数误差或触发既有有效性保护；不要求曲线严格单调，不预设哪个档位必然失败。
- 唯一变化因素：加到图像强度上的高斯噪声标准差。
- 主要指标：每档的读数有效/无效计数；有效读数的模态均方根误差和偏差。失败必须同时报告，不能只报剩下的好读数。
- 固定因素：原瞳面、相机网格、载频、窗口、参考光振幅、21 模态读取及解包裹保护。
- 不加入：光子计数、曝光、模数转换、模糊、漂移、额外帧延迟、传播或闪烁。
- 动态环境转移、模型加载/前向、训练更新、确认轨迹访问、真实数据及 SLM 动作均为零。

使用项目本地 Python、PyTorch 和 CUDA（GPU 计算），经 `src.runtime.resolve_device` 解析设备；CUDA 缺失立即失败，不回退 CPU。新实现只能放在非封存的新文件，不修改 `src/` 或 O1/O2-A/B/C 的实现、配置和测试。

## 3. 建议的固定静态样本

这是已知合成光场诊断，不是新的完整天气数据。以下数量和定义已固定到新执行配置 `configs/experiments/observation_bridge_o2_d1_read_noise_v1.yaml`，不根据结果调节。

| 项目 | 建议设置 |
|---|---|
| 原受控样本 | 复用 O2-A 的 47 个静态样本定义；不执行 O2-A 主入口、不改原输出 |
| 子空间外样本 | 新增 8 个含非 21 模态相位的完整光场，避免只在“标准答案空间”内检查 |
| 独立噪声重复 | 每个光场 16 张标准正态图，各档共享同一张图再乘不同标准差 |
| 噪声标准差 | `0, 0.001, 0.01, 0.1, 0.3, 1, 3, 10`，任意合成强度单位 |
| 总读取尝试 | `55 × 16 × 8 = 7,040`；每档 880 次 |
| 模型推理 / 动态转移 / 训练 | `0 / 0 / 0` |

新完整相位样本的可实现定义：以原 64×64 瞳面坐标 `x,y ∈ [-1,1]` 构造 `sin(6πx)cos(4πy)`，用联合常量＋原 21 模态最小二乘去除其子空间部分，得到 `h`。令 `h` 的瞳内均方根为 1；若残差范数非有限或低于 `1e-8`，设计检查失败，不换函数。添加幅度 `±0.1、±0.2、±0.4、±0.8 rad` 的 `h`，并叠加种子 `8500000` 生成的 8 组低阶系数（每系数标准差 `0.02 rad`）。该相位只用于生成器与测量后的审计，绝不作为测量输入或失败回退。

所有无噪声源相位先检查原 `1.5 rad` 邻域跳变等采样前提；不满足即停止设计检查，不自动缩小幅度让它通过。每个光场使用完整复场生成干涉图，不能先压到 21 模态；测量器只接收当前强度图。

噪声种子为 `8501000 + 55×重复索引 + 样本索引`，索引从 0 开始；重复 16 次，每个样本/重复一枚独立种子。已核对 15 份历史声明和两模式/单元命名空间互斥。技术冒烟使用额外相位种子 `8510000`、噪声基址 `8511000`，技术单元保留 `852xxxx`，与正式不同；不要根据结果修改种子。原 47 个已知受控样本定义有意复用，不冒称全新天气。

这个静态样本量只用于建立合成曲线，没有覆盖自然大气总体或给出闭环统计功效保证。47 个旧受控定义也不是 47 份独立天气。

## 4. 公平性、失败处理和停止条件

同一光场、同一重复只抽一张标准正态图，所有档位复用，零噪声档也使用本次抽图后乘零，不另抽一张。共 880 张独立噪声图，各档记录同一抽样后的随机状态指纹。先记录原强度和负值比例，再按原规则把负强度裁剪为零。每档记录实际强度均值及噪声相对尺度，不能把任意单位说成真实相机的电子数或数字灰度单位。

保留原重建保护，不降低最低强度、邻域跳变或环路一致性阈值。**有效读数先返回，随后才用已知相位计算审计误差**；不得让误差真值参与选窗口、纠正读数或筛选成功样本。

本轮没有控制动作，因此可把预先列出的测量保护拒绝记为一个“无效读数”，继续下一个既定静态样本。它不是失败后重试同一个样本，也不是将坏读数补成真值。实现前必须明确可记录的拒绝类型和原始原因；意外异常、CUDA 故障、配置/来源变化、非有限输入、抽样计数错位立即停止，保存原始错误，不自动重试。零噪声档未达到原理想最大模态误差 `≤0.001 rad` 或出现无效读数，也立即停止。

7,040 次是**预定尝试预算**，不是保证得到 7,040 个有效读数。普通噪声档的无效比例属于结果，不因无效而换档、换样本、缩小噪声或放宽保护。全表保留误差超标和无效记录，审计不存在则标为缺失及原因，不伪造数值。

报告每档 `无效数 / 880`，并按受控/子空间外组分别报告。模态误差均值、95 分位、最大值和各模态偏差**只能对有效读数计算，必须邻列显示其有效分母和无效数**；禁止把有效子集的低误差解释为整档可靠。无效样本不插补零误差，不混合有效和无效样本做普通均值。

相对各自无噪声读数另报误差变化，独立真值用于审计目标，不将“无噪声误差”直接当真值。参考 `0.001、0.01 rad` 等读数误差量级的位置，不用它们替换既有技术目标。原噪声均值 `≤0.01 rad`、95 分位 `≤0.02 rad` 可以作为诊断参考，**不是本轮挑好样本或收益放行的门槛**。

仅报告预定样本与重复的合成曲线，不做 p 值或多重比较显著性排名，不外推真实相机精度。这里的噪声重复不是新的训练初始化或天气；不得把 7,040 次读取当作 7,040 份独立天气。若整个固定网格都没有形成目标压力，报告“范围不足”，停止后再由用户决定新版扫描，不自动扩展。
