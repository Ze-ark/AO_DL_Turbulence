# 训练与评估流程

本文档说明从数据导出到模型训练、仿真评估、真实验证的完整流程。

## 1. 准备 Python 环境

项目使用 Python 3.13，并强制使用 CUDA GPU。

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

检查 CUDA 是否可用：

```powershell
.\.venv\Scripts\python.exe -c "import torch; print(torch.__version__); print(torch.cuda.is_available()); print(torch.cuda.get_device_name(0))"
```

期望看到：

```text
torch.cuda.is_available() = True
```

## 2. 导出数据

先导出仿真训练数据：

```matlab
simulate_gaussian_turbulence_dataset( ...
    fullfile(pwd, 'data', 'raw_matlab_exports', 'sim_gaussian_v1.h5'), ...
    1000, ...
    256)
```

再导出真实验证数据：

```matlab
export_real_offaxis_validation_dataset( ...
    fullfile(pwd, 'data', 'real_validation', 'real_offaxis_2x_validation.h5'), ...
    'E:\加扩束镜\2倍放大', ...
    200, ...
    [256 256])
```

## 3. 训练模型

运行：

```powershell
.\.venv\Scripts\python.exe -m src.train_compensation --config configs\sim_gaussian_v1.yaml
```

训练读取：

```text
data/raw_matlab_exports/sim_gaussian_v1.h5
```

训练输出：

```text
outputs/train_sim_gaussian_v1/loss_history.csv
checkpoints/sim_gaussian_v1_best.pt
```

`loss_history.csv` 记录：

```text
epoch, train_total, test_total
```

其中 `test_total` 是仿真测试集 loss，不是真实实验验证结果。

## 4. 仿真测试集评估

运行：

```powershell
.\.venv\Scripts\python.exe -m src.evaluate_compensation --config configs\sim_gaussian_v1.yaml
```

输出：

```text
outputs/eval_sim_gaussian_v1/metrics_by_strength.csv
outputs/eval_sim_gaussian_v1/comparison_first_batch.png
```

主要指标：

```text
complex_corr   复场相关系数，越接近 1 越好
intensity_mse  强度均方误差，越小越好
phase_rmse     相位均方根误差，越小越好
strehl_ratio   峰值强度比例，通常越高越好
rc2            质心漂移平方，越小越好
```

## 5. 真实实验验证

运行：

```powershell
.\.venv\Scripts\python.exe -m src.validate_real_experiment --config configs\sim_gaussian_v1.yaml
```

输入：

```text
data/real_validation/real_offaxis_2x_validation.h5
```

输出：

```text
outputs/real_validation_2x/real_validation_summary.csv
outputs/real_validation_2x/real_validation_examples.png
```

真实验证 summary 按温差分组，包含：

```text
temperature         温差
frame_count         帧数
energy_mean         平均总能量
peak_mean           平均峰值强度
centroid_x_var      x 方向质心方差
centroid_y_var      y 方向质心方差
rc2                 centroid_x_var + centroid_y_var
phi_corr_abs_mean   预测补偿相位绝对值均值
phi_corr_std_mean   预测补偿相位标准差均值
```

注意：真实实验验证没有无湍流真值，因此不能直接计算真实数据上的 `phase_rmse` 或 `complex_corr`。

## 6. 自动化测试

运行：

```powershell
.\.venv\Scripts\python.exe -m pytest -q
```

测试覆盖：

```text
HDF5 数据读取
真实复光场 HDF5 读取
ResUNet 输出尺寸
复场补偿损失
仿真评估指标
CUDA/GPU 运行检查
Matplotlib 非交互式后端
```
