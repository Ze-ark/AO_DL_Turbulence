## 四组必须通过的检查

### A. 因果与信息权限

1. 策略只接受合法79维帧、8帧历史及掩码。训练物理状态通过单独对象传入损失计算，不进入策略输入。
2. 保持当前合法历史完全不变，替换未来相位屏、硬件档位标签和审计真值，当前策略输出必须完全相同。未来结果可以不同，当前决策不能不同。
3. 构造脉冲请求，逐帧验证请求、队列、实际相位、功率作用时刻与下一观测。检查延迟0、2、3帧及稳定比例0.5、1.0。
4. 在解析无噪小例子验证伪开环符号`d_hat=r-a_hat`，不是`r+a_hat`。
5. 审计`info`里的真实施加模态、未来噪声、Strehl等不能被策略加载器取出。训练目标只计算规定的功率及动作代价。

### B. 前向物理一致

拟用12个独立诊断天气（每类4个）、六档硬件误差、每回合200帧；对相同预置请求分别运行原仿真器和新适配层。应覆盖零动作、脉冲、反向、接近约束边界及持续请求。

- 比较每一步的请求、延迟相位、配准后相位、实际施加相位、当前功率和下一残余。
- 同精度相位/模态最大绝对误差不超过`1e-6 rad`，功率最大绝对误差不超过`1e-6`；随机流及终止时点必须一致。
- 量化自定义反向函数的前向直接返回原量化结果，避免`x+(q-x)`浮点抵消引入无意差异。
- 默认不放宽容差。若底层GPU算子不确定导致失败，保存差异定位原因，不将失败包装成通过。

预算：`12×6×200×2=28,800`次前向转移。

### C. 连续部分的数学梯度

单独标记为数值测试：临时关闭量化、选择不触及限幅拐点的输入，保留队列与稳定过程。不能用这组较容易的环境报告性能。

执行前明确：本组使用三种受控、随时间变化的小相位数值探针×六档设置，不是三类随机湍流的性能试验；随机湍流在B、D组检查。各取4个固定方向，在16步完整响应上比较自动梯度与中心有限差分。每方向计1次求梯度前向和正负2次有限差分前向，共`3×6×4×3×16=3,456`个前向样本步；反向另计。方向、差分步长和容差在执行配置事前冻结。

以双精度数值测试检查`|自动导数-差分导数| <= 1e-5 + 1e-3×|差分导数|`；非光滑点另测单侧行为，不强行使用中心差分。零响应延迟段、队列到期段、饱和段都要有确定性单元测试。

### D. 量化代理方向是否能通过原仿真器

使用B组相同12个天气、六档硬件，冻结旧积分器。只对一个贯穿全回合的11维小修正偏置求方向，不更新网络或优化器，不把已知天气梯度当可部署控制器。

- 原点偏置为零，对完整200帧训练目标求梯度，将方向按最大绝对分量归一化；梯度非有限或整体为零须标记失败/不可判断，不能除零。
- 用原硬仿真器评价零、正负0.10、正负0.25、正负0.50倍方向。七条分支共享完全相同的天气、噪声随机流、初始化和终止规则。
- 主检验固定0.25倍；另外两档只报告敏感性，不能看结果改选有利尺度。
- 工程通行条件：正向相对反向的目标差在至少9/12个天气为正（每个天气先平均六档），六档各自的平均差均不为负，且正向相对零偏置的总体平均目标差大于0。
- 量化死区和完全并列必须报告，不删掉后再算比例。安全与非有限检查仍须通过。

这是低成本的训练方向检查，不是统计确证、算法性能、可学习性或硬件安全证明。即使通过，策略仍可能学不到这个方向。

预算：`12×6×200=14,400`次求梯度前向；`12×6×7×200=100,800`次硬模型评价转移。与B、C合计147,456个前向样本步，反向、重算和单元测试另计；软件必须逐项记账，不将全部称为独立数据。
