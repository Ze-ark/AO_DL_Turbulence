## 先看这一页就够了

推荐新路线：**强预测控制器负责基本补偿，神经网络只做小修正；训练时由光学仿真直接指出修正方向。** 暂称“物理教练型残差控制”。它是本项目当前最值得优先验证的候选，不是已经证明的最优算法。

过去两条路线中，SAC（软演员评论家）要先学会给动作估价；R4要先预测未来功率，再从许多动作中挑选。它们都增加了一层可能判断错误的模型。新方案利用现有光学公式计算动作怎样影响整段补偿效果，不再训练这两个打分网络。

可以把它理解成：旧方案请一个学生猜“这样调会不会更好”；新方案先在虚拟光学实验室里计算“往哪个方向调会更好”，再教一个只能看当前观测的小控制器。真正运行时，不需要反复试许多动作，也看不到未来答案。

推进顺序只有四步：

1. **先检查物理教练是否靠谱。** 量化、延迟、限幅都保留；计算出来的改进方向必须经原仿真器核查。
2. **建立强传统预测基座。** 不只和旧积分器比较，也和能提前预测扰动的传统控制比较。
3. **再训练小修正策略。** 先保持21个控制模态、11个学习修正量，不直接扩到256维。
4. **独立考试。** 换没见过的完整湍流回合；没有达到门槛就如实停止，不改题目或降低及格线。

当前下一步是第1步[R5-0验证计划](S4-D2-R5-0物理梯度与因果接口验证计划.md)，不是让用户立即开始长训练。

## 研究问题、假设和可失败条件

- 问题：在相同合法观测、动作空间和硬件误差下，直接利用可微光学物理训练的残差策略，能否比最强传统预测控制器获得至少1%的平均桶内功率增量，同时不恶化安全指标？
- 主假设：去掉学习型功率预测和价值自举，使用完整闭环物理梯度训练，可以减少“模型认为好、实际执行不好”的偏差。
- 竞争解释：有限21维观测本来就不足、SLM量化使梯度方向失真、传统预测基座已用尽可获得收益，或优化仍陷入局部解。
- 可证伪：梯度检查不通过，或在硬约束原仿真器上不能超过强基线，就不支持主假设。不会把更大网络当作默认补救。

## 技术设计：只让必要的部分学习

### 1. 观测和动作不偷偷升级

沿用`src/rl/r4_observation.py`的79维合法单帧、8帧历史和有效掩码：带噪残余21维、累计请求21维、因果执行器估计21维、上一修正11维、已到达功率和时间标签。来源继续标为`simulation_residual_proxy_not_holography`。

不能输入真实施加相位、真实配准、未来相位屏、隐藏硬件档位或无噪科学指标。缺失观测和超时必须显式记录；无效观测不得伪造为零波前。

保留R4的`project_request`语义：11个学习修正分量每步最多0.0125 rad，其余累计、范数和单步限制不变。需特别注意：现有传统`anchor_delta`实际输出全部21维；旧`anchor_modes=10`还用于限制范数的数值尺度，**不能误解为基座只控制前10维**。

不从21个模态捏造完整复光场。当前控制器没有全空间相位和振幅，因此不能在部署时用真实全场直接做光学搜索；完整物理场仅存在训练仿真器内部。未来若接入全息复场，所有对照必须共享同一观测，并另立数据契约。

### 2. 先把“湍流”和“自己施加的补偿”分清

用`a_t^-`表示动作前实际SLM状态，`a_t^+`表示处理新请求后的状态，`d_t`表示当前湍流。当前代码的顺序是：

```text
观测 r_t = 投影(d_t + a_t^-)
→ 发出请求 → 排队、量化、配准、限速、稳定过程 → a_t^+
→ 计算当前功率 P(d_t + a_t^+)
→ 推进湍流 d_(t+1) → 返回下一观测 r_(t+1)
```

若使用伪开环估计，正确符号是`d_hat_t = r_t - a_hat_t^-`，不是加号；执行器估计必须只用历史请求和名义标定。真实执行器状态只能审计。估计误差在配准/饱和时未必小，不能把它当成已经得到的真实湍流。

### 3. 强传统基座

在新训练/开发天气上比较：冻结旧积分器、伪开环线性预测控制、数据驱动子空间预测控制。后两者至少要显式处理历史请求、延迟和同一个约束投影，不复用R4的学习型功率输出作为评分。

基座在开发集选择后固定；策略训练及对照都使用这个基座。线性预测器只用训练拆分拟合归一化和参数。第一版不在确认集中在线更新系统辨识参数；在线自适应另作预注册扩展。

传统控制通过安全与完整性门槛后才允许策略训练。若强传统控制本身已最好，接受这个结论，不强行声称必须使用RL。

### 4. 小策略网络

- 时序编码：门控循环单元GRU，隐藏64维，对8帧合法历史编码；每个窗口重新初始化，不携带额外长历史。
- 输入重排：把21维`r_t`替换成`r_t-a_hat_t^-`，其他字段保留，因此不增加观测信息；由现有字段可逆恢复残余。
- 输出：64维全连接层、双曲正切输出11维修正；最终层置零，使初始策略等于所选基座。
- 零输出只指前向初值，不能切断输出层梯度；已有请求、安全投影、下一观测对策略的梯度链都要保留。
- 不沿用旧演员或评论家权重，不采用256维动作，不训练功率预测头，不训练价值函数。

隐藏64维是首版容量约束，不宣称最优；只有单独设计容量实验后才调整。

### 5. 训练：用完整物理回合直接更新策略

训练目标建议冻结为：

`J = 平均[当前已测桶内功率 - 0.01 × mean(c_t²) - 0.001 × mean((c_t-c_(t-1))²)]`

其中`c_t`为归一化11维修正，首步的上一修正为零。科学主指标仍为不加惩罚的桶内功率；Strehl（相对理想衍射光斑的峰值质量）和相位误差独立报告，不拿训练奖励替代。

按完整200帧闭环反向传播，折扣为1，无终端价值自举、无评论家。每一步后续观测由该策略真实造成，不做教师强制输入。使用梯度检查点重算节约显存，**不能为了省显存悄悄把200帧截成相互独立短段**。需要截断时必须新版本说明目标改变。

仿真器内部知道物理状态并提供梯度，但策略前向只看合法观测。这属于有物理梯度特权的模型式策略优化，不是只凭奖励试错的普通无模型RL。训练信息与普通PPO不同，必须单列，不能只按交互次数宣称更高效。

每次更新在三类湍流和六档硬件误差上均衡取18条完整回合；硬件档位不输入策略。用微批量1或2加梯度累积，逻辑批量固定18。首版建议Adam学习率0.0001、梯度范数限幅1、2,000次更新、三个独立初始化。所有配置在正式数据生成前冻结。

### 6. 量化梯度是关键风险，不是已解决问题

SLM真实前向必须保留256级量化、延迟队列、像素级配准、相位饱和、变化率和稳定时间。直接对`round`求导几乎处处为零，无法这样训练。

候选方法只在反向传播时采用直通估计，数学上写作`q_ST(x) = x + stop_gradient(q(x)-x)`。实现应使用自定义反向函数，前向直接返回原量化结果，避免浮点抵消；反向近似为恒等。**这不是量化器的真实导数，不保证优化有效**。限幅仍用分段真实导数，不把已饱和方向假装成畅通。

先用连续、非饱和的小型问题核查自动梯度与有限差分；再把得到的方向放进原硬量化仿真器做成对检查。若只能降低代理损失而不能改善硬模型回报，R5物理梯度分支停止，不靠继续训练掩盖问题。

本次仅做了CPU确定性标量检查：原量化梯度为0，直通估计梯度为1，两者前向相同。它证明风险确实存在，不证明新算法有效；完整CUDA检查尚未执行。

## 拆分、统计和“最好”的定义

天气是独立单位，同一天气的六档、所有控制器和模型种子必须在同一拆分。拟议训练256天气/湍流类，基座选择24/类，策略开发32/类，独立确认32/类。训练可反复使用训练天气，但重复次数不算新增独立样本。

新种子块见设计YAML；目前只完成显式数字检索，未完成派生随机流碰撞审计。执行前必须展开全部家族偏移、噪声/激励偏移、采样器种子，与历史命名空间检查。禁止读取R4已封存测试、3796000预留确认或S4-D3作为新训练/调参材料。

独立确认只检验一个冻结主算法；最强传统基线在R5-1确定，不按确认集更换。主门槛同时满足：

- 相对最强传统基线的平均桶内功率增量至少1%；先按天气平均六档，再计算总体均值比。
- 按三类湍流分层、天气配对重采样20,000次，绝对差的95%区间下界大于0。1%是点估计实用门槛，不等于区间下界也达到1%。
- 三策略种子的总体增量各为正；三类湍流及六档分组平均增量各为正。模型种子不冒充独立天气。
- Strehl平均值不下降、残差相位均方根误差不增加；违规、饱和、变化率受限比例的增加分别不超过0.001，沿用既有工程边界。
- 无观测泄漏、缺失回合、非有限值、请求超限或CPU静默回退。失败回合保留，不作成功样本筛选。
