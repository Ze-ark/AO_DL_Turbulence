> 这是一张可以直接照着勾选的清单。今天的目标不是训练强化学习，也不是一次搭完整光路，而是完成 H0：确认设备身份、兼容性和安全条件。

## 先记住两台 SLM 的分工

- `SLM-A`：负责制造已知扰动。
- `SLM-B`：负责施加补偿。
- 相机：看相位是否变好。
- 光功率计：看焦点是否更集中。

## 绝对不要继续通光的情况

出现以下任一情况，就先停在 H0：

- [ ] 不知道激光器的实际波长和输出功率；
- [ ] 没有与实际波长和功率相匹配的激光防护；
- [ ] 不知道光功率计探头是否支持该波长；
- [ ] 两台 SLM 的序列号与厂家校正文件无法一一对应；
- [ ] 反射光和衍射光没有安全终止位置；
- [ ] 实验室安全负责人或本单位规程要求的检查尚未完成。

## 第 1 步：拍设备铭牌

先不要开激光。拍摄并记录：

- [ ] 两台 SLM 的正面、背面铭牌和序列号；
- [ ] 两台 SLM 控制器或电源的铭牌；
- [ ] 激光器铭牌；
- [ ] 相机铭牌；
- [ ] 光功率计主机铭牌；
- [ ] 光功率计探头铭牌；
- [ ] 厂家提供的 U 盘、校正文件或软件版本页面。

设备型号通常不能只看主机。例如光功率计能否测 1550 nm，主要取决于**探头型号**。

## 第 2 步：固定设备身份

- [ ] 在第一台设备旁标记 `SLM-A / 扰动`；
- [ ] 在第二台设备旁标记 `SLM-B / 补偿`；
- [ ] 确认标签不会遮挡散热孔或进入光路；
- [ ] 将各自序列号写入器材模板；
- [ ] 将各自厂家校正文件名写入器材模板；
- [ ] 不交换两台设备的校正文件。

填写模板：

```text
configs/hardware_inventory_template.yaml
```

## 第 3 步：只开电脑和 SLM，不开激光

- [ ] 两台 SLM 分别接到独立 HDMI 输出；
- [ ] 系统缩放设为 100%；
- [ ] 关闭 HDR、夜间模式、色彩增强和自动对比度；
- [ ] 两个输出都设为设备要求的原生分辨率；
- [ ] 分别显示纯黑、50% 灰度、纯白和棋盘格；
- [ ] 确认改变 SLM-A 图案时，SLM-B 不会跟着变化；
- [ ] 记录两个设备在系统中的显示器编号。

如果图案被拉伸、裁剪、平滑或出现在错误设备上，先解决显示问题，不进入相位标定。

## 第 4 步：核对波长是否匹配

把下面四项写在同一张纸上比较：

| 项目 | 实际结果 |
|---|---|
| 激光器波长 | 待填 |
| SLM 厂家明确保证的相位标定波长 | 1550 nm |
| 相机是否能响应这个波长 | 待确认 |
| 功率计探头是否能响应这个波长 | 待确认 |

若实际激光不是 1550 nm，不能直接把厂家 1550 nm 的灰度—相位关系当成真值，必须在实际波长下重新标定。

## 第 5 步：确认功率计怎么测

光功率计不能把整束光全收进去后直接充当“补偿好坏”的主要指标。确认实验室至少有以下一种焦面选择方案：

- [ ] 聚焦透镜 + 小孔；
- [ ] 聚焦透镜 + 单模光纤；
- [ ] 聚焦透镜 + 小光阑。

暂时没有这些元件时，仍可完成设备建档和相位标定准备，但不能把整束总功率当作补偿成功证据。

## 第 6 步：做出 H0 判断

只有下面六项全部为“是”，才进入 H1：

| 检查项 | 是/否 |
|---|---|
| 两台 SLM 的序列号和分工已固定 | 待填 |
| 两个 HDMI 输出能独立显示正确图案 | 待填 |
| 每台 SLM 的厂家校正文件已正确绑定 | 待填 |
| 激光器实际波长和功率已确认 | 待填 |
| 相机与功率计探头支持实际波长 | 待填 |
| 激光安全与所有反射光终止措施已确认 | 待填 |

## H0 通过后只做一件事

不要马上训练强化学习。下一步是分别测两台 SLM 的：

```text
输入灰度 → 实际产生的相位
```

这一步称为 H1 灰度—相位标定。只有相机、激光器和功率计探头的准确型号都确认后，才能把 H1 写成具体的软件控制与采集步骤。

等待硬件信息期间，电脑端可以并行进行纯仿真 S0：修复 MATLAB 传播、接收面参考和动作敏感性测试。S0 不代表可以绕过 H0—H1 直接把 RL 动作发送到真实 SLM。
