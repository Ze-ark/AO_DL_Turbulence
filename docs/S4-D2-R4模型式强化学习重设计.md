## 先说方案

选择“有动作历史的模型式残差强化学习”，以PO4AO（面向自适应光学的策略优化）为方法基础。先学习命令怎样改变后续观测，再在学到的模型中连续优化动作。最后必须回到原物理仿真器验证完整闭环。

可以把它理解为两个学生：第一个学习“如果这样动，光会怎样变”；第二个利用这个预测练习控制。第二个学生训练后，每帧直接输出11个连续修正量。它不复用旧SAC演员或旧评论家的参数。

本次交付是可实施的算法设计与不可执行参数清单，不是训练完成。第一项实现任务为R4-0“观测、时间戳和动作响应接口验证”。

## 1. 从已有证据出发

| 已知证据 | 对设计的约束 | 不能推导出的结论 |
|---|---|---|
| A5-R1固定16步纯奖励目标通过；旧自举目标仍会改变排序 | 新策略目标不使用旧Q值或末端价值自举 | 不能证明所有时域、所有新策略的目标都稳定 |
| A7—A9扩样和输出结构修改未解决可靠收益预测 | 主要学习对象改为逐步物理响应 | 不能证明数据量永远不重要，或非线性模型一定能学好 |
| A10主门槛0/3，虽然比始终演员少损失 | 放弃旧演员/零修正二选一，学习连续动作 | 不能证明所有强化学习算法无效 |
| S3复杂动态GRU没有超过同历史岭回归 | 必须先做线性动力学强对照 | 不能因换成GRU就声称解决时序问题 |

当前明确的研究问题是：在相同观测、数据、动作约束和预测模型下，短时域模型式策略优化能否优于最强可部署传统控制器及同模型规划器？这是原技术蓝图问题的具体化，而不是声称新发明了模型式强化学习。

## 2. 先解决观测和时序定义

### 允许进入控制器的数据

- 当前及最近8帧的21维残余模态观测；当前阶段来自带噪仿真代理，未来须替换成经验证的离轴全息复场重建。
- 自己发出的21维累计请求、历史11维修正、命令时间戳、观测时间戳和有效标记。
- 已经到达的最近一次桶内功率测量及其测量时刻。光功率计需小孔/焦面选通测量；整束总功率不能替代桶内功率。
- 由已知命令历史和名义标定推得的执行器状态估计。估计必须显式标记，不能填入真实状态。

不允许作为策略/预测器输入：仿真器真实 `applied_modal`、`slm.current_phase`、真实湍流、真实配准参数、未来随机数、真实Strehl或测试档位编号。已校准且实际可获得的器件参数可作为公开配置，但不能偷用随机化后的隐藏参数。

代码依据：`src/simulation/env.py::_observation_and_info` 目前直接输出真实已生效模态；`src/rl/residual_control.py::_sensor_features` 会取前42维；`TrackingLeakyIntegratorController` 也使用实际加载量。它们在原纯仿真条件下是共同观测假设，不据此否定历史结论；R4的可部署观测轨道必须单独重新验证所有基线。旧R3学生输入分布改变后不能直接宣称仍为强基线。

### 必须锁定的时间顺序

当前环境的 `step` 顺序为：提交动作 → SLM延迟/稳定响应 → 在当前湍流下计算功率 → 推进湍流 → 返回下一观测。

因此一次训练记录是 `(history_t, requested_delta_t) -> (residual_observation_{t+1}, measured_power_t)`。返回的 `reward_power_in_bucket` 属于本次动作之后、湍流推进之前；返回观测中的功率属于推进之后。不得混成同一时刻。

真实数据接入前必须验证曝光窗、命令到达和功率采样的对齐。R4-0用0帧和3帧延迟、50%稳定比例的正负脉冲测试确定动作首次生效时刻；历史缓冲在回合边界清空，不补入未来帧。

## 3. 算法的三个模块

### A. 学习逐步动力学

输入历史和候选命令，输出下一帧21维残余模态及动作对应的一个功率值。直接预测残余观测的变化，不通过“真实残余减真实已施加相位”取得理想大气标签。

第一条模型是带动作输入的线性自回归模型（ARX），岭回归正则系数只在开发集选择。第二条候选为“冻结线性预测＋小型GRU残差网络”，GRU（门控循环单元）隐藏状态64维，3个独立初始化形成模型集合。64是网络记忆宽度，21是物理模态数，11是策略动作数，三者不能混用。

先按1、2、4、8步训练/检查多步预测；每项误差按训练集尺度归一化后等权平均。模态与功率尺度都有正下限，归一化参数不从验证/确认集计算。集合成员按完整训练回合重采样，不能拆帧重采样制造独立性。

预测功率头仍可能学不准。因此除了总体误差，必须检查正负局部动作导致的响应差、相对零修正的变化，以及闭环偏离初始数据后误差是否增长。只有低均方误差、但动作变化几乎不影响预测的模型不能进入策略训练。

### B. 用同一模型建立强规划器

模型预测控制（MPC）每次搜索未来8步的连续修正序列，只执行第一步，下一帧重算。首版使用交叉熵搜索：128条序列、4轮更新、保留16条精英序列，始终包含零修正候选；计算次数与延迟逐项记录。

MPC使用与RL相同的模型集合、观测、训练数据、规划时域、代价和安全投影。额外报告线性模型规划器、可部署积分器/跟踪积分器、岭回归预测控制。共同基座从“可部署积分器、因果估计跟踪积分器、岭回归预测控制”三类中在验证集选出，冻结其参数；该池不包含同模型MPC，避免两项主对照成为同一控制器。未重新验证的旧学生只能作为附加对照。

### C. 真正的模型式强化学习

策略为两层128宽的多层感知机，读取同样8帧历史，输出11维 `tanh` 修正。输出头初始化为零；冻结基座参数，但模拟展开时必须更新它的请求状态，不能每一步重置。

对从已采集训练轨迹抽取的起始历史，在3个冻结动力学模型内各展开8步，由策略逐步产生动作。按下式最大化模型内短期收益：

`J = mean_m(G_m) - std_m(G_m)`

`G_m = sum_{k=0..7} 0.99^k * (predicted_measured_power_{t+k} - 0.01 * mean(u_{t+k}^2))`

集合分歧项系数首版固定为1；它是保守启发式，不是具有覆盖保证的置信下界。策略通过动力学模型的梯度更新，动力学参数在该更新期间冻结，但对动作/状态的梯度不能截断。没有Q网络，没有末端价值自举，没有旧SAC经验池标签。

这一步才属于模型式强化学习：训练动作策略以优化序列收益。训练动力学模型只是监督学习；MPC直接搜索动作也不能计作“RL获益”。本版本不加入模仿蒸馏，以免混淆改进来源。

动作继续使用21模态总表示与10+11分工；RL仅控制新增11模态，单分量修正上限0.0125 rad，共享残差上限0.05 rad、最终单步上限0.15 rad，总L2预算按旧10模态锚点继承。基座、MPC、RL统一经过同一个盒约束和L2投影，累计命令上限沿用环境。

相较R3，本版本明确改变了观测契约、动力学学习和策略目标，并将隐藏真实违规率从训练奖励中移除，改为请求端硬约束及独立实际违规门槛。旧R3奖励可离线作为辅助指标，不能把跨版本奖励数值直接比较。若量化/饱和在真实仿真器中不可微，不用未经验证的直通梯度代替；策略梯度只通过已验证的学习模型及可微区域的请求投影。

## 4. 防止模型“想象中成功”

首版不进行无限在线训练：固定初始采集和最多两轮策略状态补充。每轮顺序为采集新轨迹 → 拟合动力学 → 冻结动力学 → 优化策略 → 原仿真器开发闭环验证。全过程使用CUDA，训练仍由用户在IDE启动。

如果模型内收益上升，而原仿真器的桶内功率下降，则停止提升该策略，保留结果并判为模型利用偏差候选；不能用模型内分数代替真实仿真结果。MPC与RL收到相同的新增训练数据；数据采集交互量不得从RL成本中扣除。

安全回退由非有限输入、请求越界和超出开发校准范围触发，使用共同基座；不重新接入A10收益否决模型。回退次数与被回退轨迹全部保留。集合成员一致不代表模型正确。

## 5. 有限实验路径

下面的数值是本设计的首版工程门槛，尚未经实验验证或统计功效证明。运行清单必须在正式数据生成前固定；若R4-0发现物理时序不支持8步，记录设计v2，不能在看过确认结果后改时域。

| 阶段 | 做什么 | 进入下一步的门槛 |
|---|---|---|
| R4-0 接口与动作响应 | 观测白名单、时间对齐、因果名义执行器估计、共同动作投影；12条天气回合诊断冒烟 | 0次真值输入泄漏；所有时序/配对/回合重置/投影测试通过；实际脉冲在8步内可识别，否则本版本停止 |
| R4-1 动力学与规划 | 拟合线性及GRU残差模型；原仿真器开发闭环比较MPC和最强基线 | 8步模态与功率归一化误差均优于保持模型至少5%；MPC桶内功率相对增益至少1%，完整回合配对95%区间下界>0，Strehl点估计不降，实际违规率增加≤0.1个百分点 |
| R4-2 策略学习 | 3个新策略初始化；最多两轮补充数据；与同模型MPC对照 | 至少2/3策略在开发闭环相对最强基线功率提高≥1%，且相对MPC功率点估计>0；不能只看模型内收益；达到预算后停止 |
| R4-3 一次独立确认 | 冻结全部参数，生成同条件和变化风况各96条新天气回合，完整200步闭环 | 满足下述独立门槛；否则记录负结果，不再开R4无限小修订链 |

R4-1如果GRU不优于线性模型的8步模态、功率误差各5%，使用按回合重采样拟合的3份线性模型进入MPC可行性检查，放弃“非线性模型优越”假设；不是自动加深网络。局部动作敏感性还须通过：在开发集中预先固定的可识别脉冲配对子集上，功率变化方向平衡准确率≥0.60，95%回合区间下界>0.50。可识别阈值为重复测量差标准差的3倍，阈值从训练端零动作重复估计，至少50条独立开发天气回合有有效配对，否则记为信号不足。该子集只检查能否识别动作效应；完整闭环评价必须保留小效应和负效应回合，不能按该阈值过滤。

### 数据与成本预算

- 初始训练384条独立天气回合；模型/控制器选择96条；三种湍流均分，六个硬件误差档位同权。初始训练天气分别运行基座及受限激励轨迹，200步，共 `384×6×2×200=921600` 次原仿真交互。
- 模型/控制器选择集只用于开发，不是未见测试；相邻片段始终从完整轨迹内抽取，不跨回合。
- 最多两轮补充，每轮96条新训练天气；每个策略种子运行当前策略和同模型MPC，两种采集器共享所得数据。每策略最多额外 `2×96×6×2×200=460800` 次原仿真交互，三个策略共1382400次；初始公共训练数据只存一份但计入每种方法可访问预算。
- 模型初始最多10000批/成员，后续每轮2000批/成员，批量64个片段；策略每轮最多5000批，初始加两轮共最多15000批/策略。每500批固定开发检查，保存所有检查点；选择规则提前冻结。
- 3个模型集合成员与3个策略初始化不是9条独立天气样本。策略学习使用同一集合；参数随机性与天气随机性分开报告。
- 最终同条件96条和变化风况96条必须使用全新种子，模型冻结后才生成。具体种子待R4-0全仓库命名空间扫描后写入运行清单；不得沿用A10的378号块或进入S4-D3的4000000及以上区域。当前设计不分配种子、不创建数据。
- 模型内展开、MPC候选次数、额外脉冲验证、开发评估和最终评估交互分别计数，均不能藏在上述训练预算中。
- 同一天气种子跨硬件档位或采集器的轨迹只能属于同一拆分。旧A10及更早确认数据仅追溯，不训练、不选模。

### 独立主门槛

主指标为200步完整回合的平均桶内功率；不删除启动段。按天气回合先平均六个档位，再按三种湍流分层配对重采样20000次。

同条件主比较为3个策略分别对最强传统基线、对同模型MPC，共6项；使用Bonferroni家族校正，总错误率0.05。相对增益定义为“先求配对总体均值差，再除以对应基线总体均值”，不平均逐帧比值。至少2/3策略两项校正区间下界均>0、对最强传统基线点估计≥1%，才支持RL额外收益。

还须满足：这两个策略对相应对照的平均Strehl差95%区间下界≥-0.005；每种湍流的功率点估计不为负；实际违规率增加的95%区间上界≤0.1个百分点；非有限值0次、请求投影后越界0次。三个安全指标及所有预设子组必须完整报告，不挑有利项。

变化风况同样6项单独校正，不能替代同条件主门槛。仅当两套都通过才可称“通过本项目仿真鲁棒确认”。回退率、失效回合、相位残差、请求/实际动作、延迟中位数/95分位与交互成本单独报告。若RL仅与MPC相当但更快，可探索效率价值，不能宣称性能优越或事后降低主门槛。

## 6. 可检验的创新候选

1. **面向离轴全息与慢SLM的因果观测契约**：仅用重建残余与命令历史，在隐藏实际加载相位时学习控制；与含真值的诊断轨道对照。必须经过后续HDF5观测接口验证才能形成真实系统贡献。
2. **动作响应保真门槛**：把局部正负动作响应、模型内收益和原仿真器收益三者的一致性作为策略训练前后的验证条件，验证能否减少模型利用偏差。
3. **模型共享的策略价值检验**：在同模型、同数据和相同实际延迟预算下，分清预测改进与RL策略贡献。即使结果是否定的，也可形成可复现实验结论，但不保证论文新颖性。

最小消融为去动作历史、去非线性残差、去集合分歧惩罚，每项单独改变；消融只在开发数据进行。正式额外消融需在确认数据生成前声明，不能事后挑选。当前是有文献依据的组合设计，尚未证明首次性或优越性。

## 7. 原始文献与采用边界

- [Nousiainen等，2022，Toward on-sky adaptive optics control using reinforcement learning](https://arxiv.org/abs/2205.07554)，DOI `10.1051/0004-6361/202243311`：PO4AO的动力学学习与策略优化基础。采用方法思想，不转用其性能数字。
- [Nousiainen等，Laboratory Experiments of Model-based Reinforcement Learning for Adaptive Optics Control](https://arxiv.org/html/2401.00242v1)，2023年末预印本，查阅第4—6节：观测/动作历史、模型集合和可微短期策略优化。该装置的变形镜与金字塔传感器不同于本项目；其具体历史长度、速度和时域不直接照搬。
- [Chua等，2018，Deep Reinforcement Learning in a Handful of Trials using Probabilistic Dynamics Models](https://arxiv.org/abs/1805.12114)：不确定性模型集合与轨迹采样的参考。这里的确定性集合分歧不是完整PETS概率模型。
- [Janner等，2019，When to Trust Your Model: Model-Based Policy Optimization](https://arxiv.org/abs/1906.08253)：短模型展开及模型偏差风险的参考。本方案不使用其SAC优化器，也不继承其理论保证。

文献查阅日期2026-09-06。未进行系统性新颖性检索；设计中的5%、1%、0.60等门槛均为本项目建议值，不是文献定律。

其后才提供用户IDE采集/训练命令。当前没有R4运行入口，不能把本设计YAML传给A10或R3脚本。暂不修改原数据格式；R4连续轨迹另设版本，至少含观测、命令、下一观测、功率时间索引、来源标签及独立的仿真真值审计区。真实SLM与S4-D3仍未开启。
