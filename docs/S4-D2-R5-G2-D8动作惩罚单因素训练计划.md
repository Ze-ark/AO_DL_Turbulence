# G2-D8：动作惩罚单因素训练计划

## 先说结论

[G2-D7 硬前向诊断](S4-D2-R5-G2-D7完整回合硬前向诊断审计记录.md)发现：在已有策略附近，把动作加大能提高仿真桶内功率，却会降低原训练评分。本轮只检验一个问题：**如果训练时不再为“动作幅度大”扣分，新策略的光学表现会不会变好？** 这不是已经过门槛的算法，也不意味着可以接触真实空间光调制器（SLM）。

## 两组如何做到同题比较

旧对照是已冻结的 G2-D2 `train_scale_1_75` 臂，动作惩罚权重为 `0.01`。新臂 `action_penalty_0` 只把这一权重改成 `0`；平滑惩罚仍为 `0.001`，训练评分仍基于**含噪测量桶内功率**。两组共同使用：

- 同三份 R5-2 第 2000 次更新的暖启动权重，**不是**从旧对照的第 512 次更新继续训练；每份新建空状态 Adam，学习率 `0.00003`，梯度裁剪 `1.0`。
- 同一 79 维因果观测、循环策略、积分器、安全投影、SLM 量化与延迟模型；训练与部署动作倍率均为 `1.75`。
- 每份初始化 `512` 次更新，每次 `18` 条完整 `200` 帧回合；奇数更新用标称六槽、偶数用新硬件六档。共 `3×512=1536` 次更新、`5,529,600` 次仿真物理转移。
- 与旧对照相同的 `256` 对训练天气及湍流、传感、功率噪声种子流。环境参数、代码束、旧结果和检查点哈希必须在启动前吻合，CUDA 或运行时版本不符立即停止。

旧训练没有保存每一步完整随机状态和所有 cuDNN 设置，因此“同种子、同外生随机流”**不等于逐位相同的反事实训练轨迹**。两组闭环状态会随策略更新自然分岔；评价必须在同一批新天气上重新配对重放，不能直接拿旧 G2-D3 数值与新天气数值相减。

## 训练与监控

入口为 [训练脚本](../scripts/train_s4_r5_g2_d8_action_penalty_zero.py)，参数为 [冻结配置](../configs/experiments/s4_r5_g2_d8_action_penalty_zero_v1.yaml)。正式训练**只由用户在 IDE 集成终端手动启动**：

```powershell
.\.venv\Scripts\python.exe scripts\train_s4_r5_g2_d8_action_penalty_zero.py --config configs\experiments\s4_r5_g2_d8_action_penalty_zero_v1.yaml --preflight-only
.\.venv\Scripts\python.exe scripts\train_s4_r5_g2_d8_action_penalty_zero.py --config configs\experiments\s4_r5_g2_d8_action_penalty_zero_v1.yaml
```

预期输出目录为 `outputs/s4_r5_g2_d8_action_penalty_zero_v1/`，包含 `losses.jsonl`、`progress.jsonl`、`checkpoint_manifest.json`、24 份检查点、`summary.json`、`SUCCESS.json`、随机流清单和运行环境。进度条显示总更新数、当前批次、平均损失、预计剩余时间及 CUDA 显存；日志每次更新落盘。目录已存在则拒绝覆盖；崩溃后保留已有文件和 `failure.json`，不自动重试。旧 G2-D2 的 `3072` 次更新约耗时 `7.2` 小时，本轮预算约为一半；这只是粗略算力参考，不是完成时间承诺。

已运行的独立天气 16 帧 CUDA 技术冒烟仅有 `1` 份初始化、`2` 次更新和 `576` 次转移；它检验程序链路，不产生算法排名。训练结束请通知助手；助手先**只读审计**日志、检查点、哈希和异常。训练损失变好不等于光学性能变好。

## 预先固定的下一道开发门槛

若训练完整且审计通过，才另行准备开发评价。新开发天气预留 `7,500,000 + 10i`（`i=0…31`），与训练、D3–D7 及独立确认天气分离。两种仿真硬件条件分别报告；冻结积分器（增益 `0.15`、泄漏 `0.10`）、旧 `0.01` 臂的三份模型和新 `0` 臂的三份模型在**同天气、同三类湍流、同六槽、同 200 帧、同部署倍率 1.75**下公平对照。

主指标是**无噪声仿真桶内功率**，不是训练评分。仅当两种硬件条件分别同时满足下列条件，才考虑设计一次新的独立确认：

1. 新臂高于旧 `0.01` 臂，按完整天气配对重采样的双条件 Bonferroni 校正 `97.5%` 区间下界都大于零，三份初始化和三类湍流的平均方向也为正。
2. 新臂相对冻结积分器的桶内功率收益在两条件下都至少为 `1.05%`。这只是开发余量；历史独立确认的 `1%` 门槛不变。
3. Strehl 比不下降、残差相位误差不增加；安全违规、饱和及限速三项相对旧臂和积分器的增加各不超过 `0.001`。同时报告动作请求与实际加载差距、裁剪比例、推理延迟、失败回合及交互/计算预算。

若不满足或出现动作极端/安全退化，停止这次消融路线，不在本批开发天气反复扫描惩罚权重。预留的 `7,600,000` 独立确认天气本轮**不访问**；原 G2-D3、G1 失败判定不变。全部结果均属于软件仿真，不能声称双 SLM 或自然大气闭环已通过。
