# S4-D2-R2 闭环分布漂移诊断审计记录

## 先说结论

正式诊断支持“训练数据与实际闭环状态不一致，并且模型动作会进一步放大这种偏离”。三个多层感知机（MLP）在100%动作下的桶内功率平均下降`33.0087%—42.4848%`，后期教师动作误差达到早期的`2.77—3.26`倍，状态离群比例增加`29.66—36.90`个百分点。

把动作缩小到10%后，三个MLP都出现约`0.32%—0.35%`的微小正收益，但远低于预先声明的2%门槛，六个硬件误差档位没有一个通过。因此本阶段状态为：`CLOSED_LOOP_DISTRIBUTION_SHIFT_SUPPORTED / NO_SAFE_SCALE_RECOVERY`。

这不是“神经网络完全不会”，也不能证明SAC算法本身有错。更准确的解释是：上一阶段模型在教师轨迹上学到了一部分正确方向，但部署时首先遇到与教师数据不同的传统基线轨迹；随后较大的模型动作又把系统推到更陌生的状态，形成连续反馈恶化。下一步应先用闭环状态重新收集教师标签并验证数据聚合，而不是直接增加训练轮数、更换强化学习算法或打开S4-D3。

## 为什么能判断存在两层分布差距

第一层是**部署起点就不同**。即使模型动作缩放为0%，模型在传统基线轨迹上的教师动作均方误差，已经达到上一阶段教师轨迹离线误差的约`11.64—11.99`倍；但误差在回合前后基本不增长，后期/早期比值为`0.98—0.99`。这说明学生部署时看到的状态本来就不同于教师数据，而不是只有模型出手后才发生偏离。

第二层是**模型动作产生反馈放大**。在100%动作下，早期误差达到离线误差的约`15.06—15.25`倍，后期进一步达到`41.77—49.47`倍；与0%动作的同一新轨迹相比，后期误差又放大约`3.56—4.25`倍，同时状态离群和累计请求显著增加。

因此证据支持“教师轨迹到部署轨迹的初始分布差距 + 学生动作造成的闭环累积恶化”。它不证明这是唯一根因，也不证明只要改训练数据就一定成功。
