## 2. 怎么处理容易出错的相位

先按明确声明的转置、行列翻转及共轭符号校正方向；不自动缩放、裁剪或猜测标定。然后沿光瞳内相邻像素还原连续相位，检查邻点跳变与绕行一致性；最后同时拟合“一个全局常量相位 + 原 21 模态”。

全局常量相位可以来自参考光。直接减相位均值可能改变离散模态系数，因此本版本联合拟合常量项，不删除倾斜，也不重造冻结基。常量相位只能确定到整圈 `2π`，不是绝对光学相位测量。

O1 明确拒绝未知坐标/符号/参考、零强度、光瞳孔洞、相对强度过低、非有限数值、网格不匹配、绕行不一致，以及不能满足此次 21 模态加常量假设的相位。其他设备输入也拒绝，**没有 CUDA（GPU 计算）到 CPU 的静默回退**。

重要限制：只凭包裹相位，无法发现所有空间混叠。例如每像素多转一整圈与零相位的复场不可区分。测试已保留这个反例；真实相邻相位变化足够小必须由来源/采样验证保证，不能据转换器没有报错就声称相位唯一可恢复。技术入口对已知人工答案独立检查真实邻点差；真实 HDF5（分层数据文件）仍不允许直接接入本版本。

## 3. 实际技术结果

明确种子 `831001`；CPU 小型确定性检查；46 份 64×64 人工光场及一个非方形方向例子。人工光场由同一冻结基合成，没有传感器噪声或域偏移，极小误差主要反映数学往返自洽。

| 检查 | 实际结果 |
|---|---|
| 非方形、非对称 3×5 方向例子 | 转置、双翻转与共轭校正后精确一致；不是 MATLAB 跨语言校验 |
| 21 模态各正负一次，共 42 份 | 最大系数误差 `7.647e-16 rad` |
| 固定种子的 2 份混合相位 | float32 系数读出后最大误差为 0；不代表无限精度 |
| 平滑跨 ±π 相位 | 最大系数误差 `1.288e-14 rad`；真实相位幅度最高约 `9.261 rad` |
| 同一相位加 `3.7 rad` 常量参考 | 最大系数误差 `1.406e-14 rad`；倾斜系数保持不变 |
| 对照：直接投影包裹相位 | 同一例子最大误差约 `4.15345 rad`，说明需要处理折返 |

全部预设人工例子满足 `1e-5 rad` 技术容差。单元测试另覆盖 complex64/complex128（单/双精度复数），多种常量参考、低强度/孔洞/异常数值、相位奇点、空间混叠反例及真实来源拒绝。

原 R4 因果接口的接入测试使用明确已知初态的人工记录：缺失功率保持无效，未来功率拒绝，迟到功率不能冒充当前动作标签；调用端在温差/回合切换时明确 `reset`，历史清空。**转换器本身不推断温差边界或真实采集时钟，不虚构离线控制回合。**
