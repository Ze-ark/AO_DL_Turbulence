# G2-D6：完整回合训练目标分解计划

## 先说结论

G2-D5 排除了明显的延迟梯度断链，也没有发现量化代理梯度普遍反号，但它只发出一次动作、观察五帧，不能说明原训练为何把动作学小。G2-D6 冻结两组已训练策略，在**完整 200 帧闭环**里重放原目标，分别核算含噪测量功率、无噪声仿真光学功率、动作惩罚和平滑惩罚；不训练、不挑选新模型、不打开独立确认集。

## 固定对照

- 两组等预算策略使用 G2-D2 第 512 次更新的三份初始化；部署倍率同为 `1.75`，与 G2-D3 保持一致。
- 两种仿真硬件条件、三类湍流、六档硬件槽位；同一条件下两臂共享天气种子、观测噪声和功率噪声的初始随机流，完整回合按 200 帧运行。
- 正式诊断使用新开发天气 `7,340,000` 和 `7,340,010`；短技术冒烟使用 `7,350,000`。两者与训练天气、G2-D3/D4/D5 开发天气及预留独立确认天气分离。只有 **2 个独立正式天气**，故结果定位机制，不计算或宣称独立性能门槛。
- 若可微完整回合求导可稳定实现，以统一倍率的局部径向导数分别衡量测量功率、动作惩罚和平滑惩罚的方向；它是冻结模型周围的局部敏感度，不是“重新训练后的性能预测”。

## 关键判读

如果 1.75 倍训练臂的光学功率较低，但**按原目标计算的完整回合评分较高**，说明训练目标与独立科学指标存在明确偏好冲突；这仍不自动证明某个惩罚权重是唯一原因。如果它的原目标评分也较低，则更偏向优化不足、初始化、样本泛化或闭环状态分布差异，需要下一轮无训练对照，不能直接调高奖励或重训。

无论哪种结果，都不改变 G2-D3 的 `1.05%` 开发继续门槛和封存独立确认规则，也不把纯仿真当作真实 SLM 或自然大气结果。若程序不完整、来源哈希不符、出现非有限数值或 CUDA 不可用，应停止并保留原始报错，不自动重试。
