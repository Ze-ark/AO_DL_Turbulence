## 项目状态更新：2026-08-03

Phase 3 文献结论保持不变，但项目条件已经进一步明确：

- 实验室有两台中科微星 `FSLM-2K73-P04` 相位型反射式 SLM；
- 计划由 SLM-A 生成对控制器隐藏的扰动，SLM-B 执行补偿；
- 实验室有光功率计，但是否具备焦面小孔、单模光纤或小光阑仍待确认；
- 项目采用“纯仿真优先、硬件标定并行、冻结后迁移”的新执行顺序；
- 当前静态 MATLAB—HDF5—ResUNet 流程只作为冒烟测试和静态基线，不是正式 RL 管线。

这项更新改变实施顺序和已知硬件条件，不改变本报告的文献证据判断。

## 1. 只看这一页：小白版最终决定

### 现在并行做哪几件事

1. **电脑端先修纯仿真**：完成传播、接收面参考、动作敏感性和数据拆分的 S0 Gate。
2. **实验室端查清设备**：记录两台 SLM、激光器、相机和功率计探头的信息。
3. **先不用 RL 做闭环**：显示几个已知相位，确认全息系统能测对；再加载反向校正，确认真实焦点或相位确实改善。
4. **再采集动作—结果数据**：给 SLM 小幅、安全且预先设计好的探测动作，完整记录动作前后测量和时间戳。

### 为什么现在不训练 RL

RL 需要看到“我做了动作以后，真实系统发生了什么”。当前项目只有静态复光场和标签，没有 SLM 动作后的下一帧，所以现在训练出来的只能是静态拟合，不是闭环控制。

### 什么情况下才进入 RL

同时满足以下三条才进入：

- 最简单的非 RL 闭环已经可靠工作；
- 扰动变化速度与实际控制周期相匹配，历史信息确实有用；
- 已采集的先导数据表明，简单线性控制仍留下可重复的误差。

### 七个常见缩写

| 缩写 | 中文意思 | 你现在只需记住什么 |
|---|---|---|
| AO | 自适应光学 | 测量光学误差并及时校正 |
| SLM | 空间光调制器 | 本项目用来显示校正相位的硬件 |
| RL | 强化学习 | 根据“动作后的结果”学习怎样控制 |
| SAC | 一种可重复利用旧数据的 RL | 作为第二候选，不是创新本身 |
| PPO | 一种更新较保守的 RL | 先只做仿真比较 |
| MPC/LQG | 两类经典预测控制 | RL 必须击败的强对手 |
| PO4AO | 一条先学系统规律、再学控制的 AO 路线 | 只有系统模型通过验证后才考虑 |

### 1.1 这篇研究真正要问什么

不要先问“该用 SAC 还是 PPO”，而要先问：

> **全息系统已经测出了光场，SLM 也能施加相位校正时，强化学习在有延迟、噪声和标定误差的真实闭环里，是否真的比直接相位补偿和经典预测控制更好？**

这里的“真实闭环”是：

1. 相机完成一次真实测量；
2. 控制器根据这次测量算出动作；
3. 动作真实加载到 SLM；
4. 等待 SLM 响应；
5. 再测量动作造成的真实结果。

当前项目里的静态图片和复光场数据没有第 3—5 步，因此还不能训练或证明闭环强化学习。

### 1.2 推荐主线

推荐把论文主线定为：

> **在离轴数字全息—SLM 实测闭环中，用严格的“孪生对照”检验 RL 策略是否真的有额外价值。**

这里的“孪生对照”是让两个控制器共享同一套测量、特征、系统模型、基础控制器和安全约束：

- 一个用传统数学优化计算动作；
- 一个用 RL 策略计算动作。

这样两者唯一重要差别才是“有没有使用 RL 策略”。否则，RL 即使胜出，也可能只是因为它用了更大的模型、更多历史或更多计算。

“必要性检验”很重要。全息测量能直接给出相位，最简单的控制办法就是把相位反过来加载到 SLM。强化学习只有在处理以下问题时才可能体现额外价值：

- 测量、计算和 SLM 响应之间存在延迟；
- SLM 的电压—相位关系不是理想直线；
- 标定会漂移，光路会错位；
- 湍流随时间变化，仅修正上一帧已经太晚；
- 动作存在相位范围、变化速度和空间平滑限制。

经典最优控制和预测控制早已能处理部分时延、噪声和约束问题（Kulcsár 等，2006；Konnik 与 De Doná，2015；Haffert 等，2021）<!--ref:kulcsar2006--><!--anchor:section:Phase2-6-19--><!--ref:konnik2015--><!--anchor:section:Phase2-6-20--><!--ref:haffert2021--><!--anchor:section:Phase2-6-21-->。所以 RL 必须与这些强方法公平比较，不能只与一个参数没有调好的积分器比较。

定向补检还发现，热湍流光路中的实物 SLM + TD3，以及数字全息复振幅测量 + SLM 预补偿都已经发表（Seifi 与 LoPresti，2025；Seifi 与 LoPresti，2026；Dai 等，2026）<!--ref:seifi2025--><!--anchor:doi:10.3390/photonics12100979--><!--ref:seifi2026--><!--anchor:doi:10.1109/LPT.2026.3652043--><!--ref:dai2026--><!--anchor:doi:10.1038/s41377-026-02362-x-->。因此，“用了 SLM”“做了实物 RL”或“数字全息控制 SLM”都不能作为主创新。

### 1.3 算法结论

主算法不再预先锁定。先用一批只用于摸底的先导数据走下面的决策树，选定后冻结方案，再打开封存测试数据：

1. **如果扰动没有可利用的时间规律：不做 RL。**
   研究停在标定、直接相位补偿和静态优化。

2. **如果线性模型已经预测得很好：以 LQG 或 MPC 为主。**
   此时复杂模型式 RL 没有充分理由。

3. **如果非线性模型明显更好：进入核心孪生对照。**
   同一个非线性动力学模型分别交给“受约束 MPC/轨迹优化”和“PO4AO 式 RL 策略”，比较两种决策方式。

4. **第二 RL 候选：残差 SAC。**
   经典控制器先完成大部分校正，SAC 只学习补上剩余误差。它是有价值的对照，但“积分器 + SAC”已经有直接先例（Pou 等，2022）<!--ref:pou2022--><!--anchor:section:Phase2-5.2-5-->，不能作为论文唯一创新。

5. **PPO：先只放在仿真比较中。**
   PPO 在一个特定的准静态无传统波前传感器仿真中优于同场 SAC 和 DDPG（Parvizi 等，2023）<!--ref:parvizi2023--><!--anchor:section:Phase2-5.3-11-->。暂不让它占用实物采样，是本项目在硬件成本未知时的工程选择，不代表 PPO 普遍更费数据或普遍更差。

6. **循环记忆型算法：先不做。**
   只有当“打乱历史帧”或“去掉过去动作”明显降低性能时，才说明复杂记忆结构值得加入。

一句话概括：

> **先证明存在值得预测的问题；再用相同模型比较传统规划和 RL。RL 没有独立增益，就不要为了用 RL 而用 RL。**

## 2. 最终研究问题

### 2.1 入门表述

当离轴全息能够测出复光场、SLM 能够校正相位时，RL 策略能否利用时间规律，抵消系统延迟和非理想误差，并在使用相同系统模型与数据的情况下，超过非 RL 预测控制？

### 2.2 论文表述

在以离轴数字全息重建复场作为可部署观测、以相位型 SLM 作为执行器的实测闭环中，时序 RL 策略能否在匹配真实数据访问、观测、编码器、动力学模型、基础控制器、动作约束和调参协议的条件下，相较使用同一动力学模型的受约束 MPC 或轨迹优化，提高封存动态扰动及标定、时延失配下的预注册主要指标，同时不增加动作违规、失败和回退率？

直接相位共轭、调优积分器和线性预测控制仍作为必要的外层基线。训练计算量、部署延迟和内存不强行做成相同数值，而是作为成本与性能一起报告。

### 2.3 四个必须回答的子问题

1. **时间信息真的有用吗？**
   去掉历史、打乱历史或令未来折扣为零后，RL 的优势是否消失？

2. **复杂模型真的有用吗？**
   学习到的非线性模型能否在独立序列上超过“下一帧等于这一帧”和线性 VAR/子空间模型？

3. **优势能带到实物系统吗？**
   改变 SLM 标定、增加时延抖动、换一组未见扰动后，优势是否仍然存在？

4. **优势真的是 RL 带来的吗？**
   当非 RL 规划器和 RL 共享同一非线性模型、特征和约束时，RL 是否仍然更好？

## 3. 为什么选择这种算法路线

| 方法 | 用小白语言解释 | 在本项目中的位置 | 进入实物实验的条件 |
|---|---|---|---|
| 条件成立时的直接相位共轭或约束投影 | 测到多少错误，就施加反方向校正 | 必做的最简单基线 | 相位型 SLM、共轭面、配准、相位范围和偏振检查通过 |
| 逐模态泄漏积分器 | 每次只改一部分，避免来回振荡 | 必做的经典基线 | 扫描并固定最优增益 |
| 数据驱动 LQG、VAR 或 MPC | 从过去几帧预测下一帧，再提前校正 | 必做的强预测基线 | 使用与 RL 完全相同的数据 |
| 同一非线性模型 + 受约束 MPC 或轨迹优化 | 用与 RL 相同的系统模型，但不用 RL 选动作 | **识别 RL 贡献的核心对照** | 非线性模型通过验证 |
| 同一非线性模型 + PO4AO 式策略 | 先学系统规律，再在模型中练一个快速策略 | **条件性主 RL 候选** | 先导决策树选择它，并冻结方案 |
| 残差 SAC | 经典控制先做大头，RL 只补遗漏 | 第二 RL 候选 | 有安全动作投影和回退控制器 |
| PPO | 用近期采集的一批经验更新策略 | 先做仿真比较 | 除非先导结果支持实物比较的必要性 |
| 循环记忆型策略 | 用内部记忆保存过去状态 | 条件性扩展 | 历史反事实检验证明确有必要 |

模型式 AO 强化学习已经有仿真、实验台和真实天文闭环证据（Nousiainen 等，2022；Nousiainen 等，2024；Nousiainen 等，2026）<!--ref:nousiainen2022--><!--anchor:section:Phase2-5.2-6--><!--ref:nousiainen2024--><!--anchor:section:Phase2-5.2-7--><!--ref:nousiainen2026onsky--><!--anchor:section:Phase2-5.2-9-->。这说明路线具有可行性，但也意味着“使用 PO4AO”本身不是创新。

SAC 适合连续动作并能重复利用旧数据（Haarnoja 等，2018）<!--ref:haarnoja2018--><!--anchor:section:Phase2-7-24-->，残差学习也有一般机器人学依据（Johannink 等，2019）<!--ref:johannink2019--><!--anchor:section:Phase2-7-25-->。但是，AO 中已有“积分器 + SAC”和“监督重构 + SAC”的直接研究（Pou 等，2022；Pou 等，2024）<!--ref:pou2022--><!--anchor:section:Phase2-5.2-5--><!--ref:pou2024--><!--anchor:section:Phase2-5.2-8-->。因此 SAC 应是比较对象，不应是论文标题里的唯一卖点。

## 4. 候选创新点排序

| 候选想法 | 与已有工作的距离 | 可做性 | Phase 3 判断 |
|---|---:|---:|---|
| 只做“积分器 + 残差 SAC” | 很近 | 高 | 不作为主创新 |
| 只做“ResUNet + RL” | 很近 | 中 | ResUNet 可作基线、编码器或教师，不作为主创新 |
| 只用焦平面图像训练 RL | 已有多条路线 | 中 | 赛道较拥挤，不优先 |
| 只做 SLM 实物 RL 闭环 | 已有热湍流 TD3 实物路线 | 中 | 不作为主创新 |
| 只做数字全息复场 + SLM 补偿 | 已有直接实物近邻 | 高 | 不作为主创新 |
| 离轴全息时序观测下检验 RL 增量价值 | 尚未直接命中同题组件匹配研究 | 中 | **候选科学空缺，仍需投稿前查重** |
| 同一非线性模型下比较 MPC 与 RL 策略 | 现有论文很少做严格组件匹配 | 中 | **推荐的因果识别与方法学创新** |
| 学习 SLM 非线性和时延模型，再做受限控制 | 有邻近路线，无项目特定验证 | 中 | 工程基础，不单独作为创新 |
| 像素级多智能体直接控制整块 SLM | 有高维 AO 邻近工作 | 低 | 首篇研究不做 |

### 4.1 推荐组合

建议把三个部分组合成一个完整贡献：

1. **实验贡献**：把现有离轴全息复场重建变成带有真实动作后测量和完整时间戳的在线闭环；
2. **识别贡献**：用安全外部激励辨认 SLM 动作的因果作用，而不只是学习扰动相关性；
3. **科学贡献**：共享同一模型、特征和约束，直接比较非 RL 规划与 RL 策略。

热湍流 SLM 实物 RL、数字全息复振幅测量加 SLM 补偿，以及散射介质中的 SLM 实物 RL 均已有发表近邻（Seifi 与 LoPresti，2025；Seifi 与 LoPresti，2026；Dai 等，2026；Zhang 等，2026）<!--ref:seifi2025--><!--anchor:doi:10.3390/photonics12100979--><!--ref:seifi2026--><!--anchor:doi:10.1109/LPT.2026.3652043--><!--ref:dai2026--><!--anchor:doi:10.1038/s41377-026-02362-x--><!--ref:zhang2026sdrl--><!--anchor:doi:10.1016/j.optlaseng.2026.109740-->。目前仍可防守的只是更窄的候选问题：“离轴全息时序观测下，RL 相对共享同一模型的非 RL 控制是否有增量价值。”这仍不是“首次”证明。

### 4.2 最有价值的负结果

如果严格实验发现：

- 直接相位共轭已经达到最好结果；
- 线性预测控制与模型式 RL 表现相同；
- 同一非线性模型下，MPC 与 RL 策略表现相同；
- 打乱历史后 RL 几乎不受影响；
- RL 的微小增益小于系统重复性误差；

那么结论应是“在该测量充分、慢速 SLM 系统中，RL 没有必要”。这不是实验失败，而是一个清晰、可复查的科学边界。

## 6. 六个证据主题

### 6.1 RL 控制 AO 已经被证明“能做”

证据覆盖仿真、光学实验台、显微系统和实测天文闭环。因此，本项目不需要再把“RL 能否输出一个相位动作”当成核心问题。真正的问题是：在本项目的全息观测和 SLM 硬件条件下，它是否比简单且强的替代方法更值得使用。

结论强度：**强**。
不能推出：RL 在本项目中必然更好。

### 6.2 时间历史可能有用，但不能默认有用

模型式、循环式和预测式工作共同支持动态信息的重要性（Nousiainen 等，2021；Landman 等，2021；Haffert 等，2021）<!--ref:nousiainen2021--><!--anchor:section:Phase2-5.2-3--><!--ref:landman2021--><!--anchor:section:Phase2-5.2-4--><!--ref:haffert2021--><!--anchor:section:Phase2-6-21-->。但如果 SLM 比扰动变化慢很多，或者实验只使用准静态相位屏，历史模型可能没有实际价值。

结论强度：**中到强，取决于实测时间尺度**。
必须补的证据：相机采集、重建、推理、传输、SLM 稳定各阶段的时间戳。

### 6.3 SLM 与全息近邻已经出现，精确空缺变得更窄

已有研究使用 WFS 遥测、焦平面图像、低维探测器和图像质量指标。全息波前测量已经进入闭环 AO（Zepp 等，2022）<!--ref:zepp2022--><!--anchor:section:Phase2-8-28-->；定向补检又发现实物 SLM + TD3 热湍流控制、数字全息复振幅测量 + SLM 预补偿以及 SLM 散射波前整形 RL（Seifi 与 LoPresti，2025；Seifi 与 LoPresti，2026；Dai 等，2026；Zhang 等，2026）<!--ref:seifi2025--><!--anchor:doi:10.3390/photonics12100979--><!--ref:seifi2026--><!--anchor:doi:10.1109/LPT.2026.3652043--><!--ref:dai2026--><!--anchor:doi:10.1038/s41377-026-02362-x--><!--ref:zhang2026sdrl--><!--anchor:doi:10.1016/j.optlaseng.2026.109740-->。

结论强度：**“SLM + RL”与“数字全息 + SLM”不再是空缺**。
仍未直接命中的候选问题只有：离轴全息复场作为连续时序观测时，RL 策略相对共享同一模型的非 RL 规划器是否有额外价值。该窄空缺仍为中等置信度，投稿前必须继续查重。

### 6.4 硬件和实测可行，但不能直接迁移

AO RL 已有实验台和真实天文闭环结果，SLM RL 也已有热湍流和散射介质实物结果（Nousiainen 等，2024；Nousiainen 等，2026；Seifi 与 LoPresti，2025；Zhang 等，2026）<!--ref:nousiainen2024--><!--anchor:section:Phase2-5.2-7--><!--ref:nousiainen2026onsky--><!--anchor:section:Phase2-5.2-9--><!--ref:seifi2025--><!--anchor:doi:10.3390/photonics12100979--><!--ref:zhang2026sdrl--><!--anchor:doi:10.1016/j.optlaseng.2026.109740-->。这证明“学习控制能进入真实光路”，但不证明它能适应本实验室未知型号 SLM 的刷新速度、相位查找表、迟滞、温漂和像素耦合。

结论强度：**一般硬件可行性强，本设备可行性未知**。

### 6.5 约束与公平基线不是附属项

动作正则化和约束 RL 已有基础（Parvizi 等，2026；Achiam 等，2017）<!--ref:parvizi2026--><!--anchor:section:Phase2-5.3-14--><!--ref:achiam2017--><!--anchor:section:Phase2-7-26-->，但真实 SLM 仍需要控制器之外的硬投影：限制总相位、单帧变化、模态范围、空间梯度以及量化。与此同时，LQG、MPC 和数据驱动预测控制必须得到与 RL 相同的观测、数据和调参预算。

结论强度：**强**。

### 6.6 没有“普遍最好的 RL 算法”

SAC 在动态高维 AO 中有成功证据，而 PPO 在一个特定准静态仿真中胜过 SAC 和 DDPG（Pou 等，2022；Parvizi 等，2023）<!--ref:pou2022--><!--anchor:section:Phase2-5.2-5--><!--ref:parvizi2023--><!--anchor:section:Phase2-5.3-11-->。差异可能来自观测、动作维数、奖励、扰动速度、训练数据复用方式和比较预算，而不是算法名称本身。

结论强度：**中**。
研究含义：先用本系统的小规模仿真筛选，再让硬件门槛决定主算法。

## 7. 证据冲突与解释

### 7.1 SAC 与 PPO 的排序相反

- Pou 等（2022）<!--ref:pou2022--><!--anchor:section:Phase2-5.2-5-->支持 SAC 在动态高维 AO 中的可行性。
- Parvizi 等（2023）<!--ref:parvizi2023--><!--anchor:section:Phase2-5.3-11-->在准静态低维反馈仿真中报告 PPO 优于 SAC 和 DDPG。

解释：这是**条件不同**，不是两篇论文必有一篇错误。最合理的处理是同预算仿真比较，不做普遍排名。

### 7.2 模型式与无模型路线都报告成功

- PO4AO 先学习动力学（Nousiainen 等，2022）<!--ref:nousiainen2022--><!--anchor:section:Phase2-5.2-6-->。
- 多智能体 SAC 直接从交互数据学习控制（Pou 等，2022）<!--ref:pou2022--><!--anchor:section:Phase2-5.2-5-->。

解释：模型式方法通常更节省昂贵实物交互，但会受错误模型误导；无模型方法少一个模型偏差来源，却可能需要更多实测数据。本项目的 SLM 可能较慢，因此先给模型式方法机会，但必须设置“模型胜过线性预测”的硬门槛。

### 7.3 “RL 胜过积分器”与“RL 只追平强方法”

部分研究显示 RL 比标准积分器更好，但焦平面模型式控制研究也提示，强基线可非常有竞争力（Nousiainen 等，2026）<!--ref:nousiainen2026focal--><!--anchor:section:Phase2-5.3-16-->。

解释：一个参数固定或未充分调优的积分器是弱基线。论文结论会随基线强度改变，因此必须加入最优逐模态积分器、线性预测和受约束 MPC。

### 7.4 相位残差与最终成像指标不完全相同

波前或全息残差容易高频测量，但可能漏掉非共路误差和科学焦平面的像质；焦平面指标更接近最终目标，却通常更慢、更模糊。

解释：控制观测可以使用全息复场，但主要评价最好来自独立焦平面相机、光纤耦合效率或独立成像指标。若没有独立评价通道，必须明确奖励与评价共用信号可能带来的偏差。

### 7.5 已有 SLM 成功不等于能迁移到本设备

真实天文预测控制和热湍流 SLM–TD3 都证明实物控制可以落地（Nousiainen 等，2026；van Kooten 等，2022；Seifi 与 LoPresti，2025）<!--ref:nousiainen2026onsky--><!--anchor:section:Phase2-5.2-9--><!--ref:vankooten2022--><!--anchor:section:Phase2-6-22--><!--ref:seifi2025--><!--anchor:doi:10.3390/photonics12100979-->，但观测、光路、频率和目标都与本项目未知型号 SLM 不同。Seifi–LoPresti 系列每步约为秒级或亚秒级，也不能证明高速主环。

解释：只能迁移实验思想，不能迁移速度或性能数字。

### 7.6 测量越完整，RL 的必要性反而越需要证明

全息复场同时给出振幅和相位，这让直接物理补偿更容易。它增强了系统可控性，却削弱了“必须用复杂 RL 才能控制”的论点。

解释：把 RL 的作用限定为**预测未来、补偿非线性和处理失配**，并通过反事实实验逐项验证。

## 8. 知识空缺与证据汇聚图

### 8.1 最关键的五个空缺

1. **精确空缺尚未完全核验**：SLM–RL 和数字全息–SLM 已有直接先例；尚未命中的只是“离轴全息连续观测 + 时序 RL + 共享模型的非 RL 对照”，仍需检索专利和会议工作。
2. **SLM 动力学未知**：型号、相位型或振幅型、反射或透射、工作波长、刷新率、稳定时间、相位范围、位深和查找表均未记录。
3. **没有动作—响应数据**：现有真实数据不能回答“显示某个相位后，下一帧发生了什么”。
4. **独立评价通道未知**：如果同一份全息重建既当观测又当最终评分，控制器可能只优化测量算法的偏差。
5. **RL 增益来源未知**：尚不清楚需要的是时间预测、SLM 非线性补偿，还是简单的标定修正；若不做同一模型的孪生对照，无法分开这些来源。

| 判断 | 支持证据 | 独立性检查 | 限制证据 | 当前置信度 |

## 9. 统一理论框架

从这里开始使用三类标签：

- **[文献证据]**：来源论文直接支持；
- **[项目推断]**：由当前代码、数据或已知硬件条件推得；
- **[工程建议]**：尚待实验验证的实施方案。

未单独标注的 H0—H5 门槛均属于工程建议，不应写成已经被本项目验证的事实。

### 9.1 把系统想成“看不全的动态游戏”

**[项目推断]** 真正状态并不只是一张相位图，还包括：

- 正在变化的湍流；
- SLM 液晶和温度状态；
- 相机与 SLM 的时钟差；
- 光路漂移和像素配准误差。

这些量不能全部直接看到，因此可把问题写成“部分可观测决策过程”。

### 9.2 观测

**[工程建议]** 首轮不要把完整 `256 × 256` 图像直接喂给 RL。先使用低维相位模态、振幅特征和时间信息：

- 由 SLM 影响矩阵和扰动能量决定数量的 Zernike 或 KL 相位模态系数；
- 少量振幅、闪烁或光强特征；
- 前几帧已真实加载的 SLM 命令；
- 每一帧的采集、重建和显示时间戳；
- 丢帧、无效帧和 SLM 未稳定标记。

模态数不预先固定为 8—15。先测哪些模态确实能被 SLM 稳定控制，再选择能覆盖主要扰动能量且数值条件良好的最小集合。现有 ResUNet 可以作为静态补偿基线、特征编码器或仿真教师，但不自动成为主控制器。

### 9.3 动作

**[工程建议]** 首轮动作使用经过 H1 筛选的低阶可控模态**增量**，而不是直接控制每个 SLM 像素。每次动作经过硬投影，确保：

- 总相位不超过 SLM 实测范围；
- 单帧变化不超过安全值；
- 模态系数处于标定范围；
- 空间相位梯度不过大；
- 符合 SLM 位深和查找表量化。

### 9.4 奖励与主要评价

动作真正加载且 SLM 稳定后再计算奖励。一个可检验的初始形式是：

```text
奖励 =
  - 相位残差波动
  + 焦平面质量
  - 动作变化代价
  - 饱和与违规代价
```

训练奖励可以是组合量，但论文应预先固定一个主要评价指标，例如：

- 时间平均归一化 Strehl；
- 归一化焦点峰值或环围能量；
- 光纤耦合效率。

### H0-E 对应的评价门槛

- 有独立焦平面相机、功率计或耦合效率通道：可以把成像或传输改善设为主要终点。
- 没有独立通道：主要终点只能写成“全息重建的残余相位改善”，不能进一步声称真实成像质量或通信性能改善。

交替测量或独立离线重建可以作为补充，但不能完全替代真正独立的科学面评价。

### 9.5 模型式 RL 的进入门槛

只有同时满足下列条件，模型式 RL 才进入主实验：

1. 在完全独立的动作—响应序列上，单步预测优于“保持上一帧”；
2. 多步滚动误差不会迅速发散；
3. 非线性模型稳定优于线性 VAR 或子空间模型；
4. 训练数据覆盖拟使用的安全动作范围；
5. 在不同扰动、光强和标定条件下报告误差与不确定性。
6. 用模型集成或其他方法估计不确定性，并能识别超出训练范围的观测；
7. 在真实控制前完成影子运行：只计算动作但不执行，检查潜在越界；
8. 先用短预测范围和很小的 RL 残差，验证安全后再逐级放权。

如果第 3 条不成立，结论不是“继续调更大的网络”，而是优先使用更简单的 LQG、VAR 或 MPC。

## 10. SLM 实验硬门槛

### H0：先给硬件建档

在写 RL 环境前，记录：

- SLM 品牌和完整型号；
- 相位型还是振幅型，反射式还是透射式；
- 工作波长、分辨率、像素间距、位深；
- 标称刷新率和接口；
- 相位调制范围；
- 厂商查找表是否与当前波长匹配；
- 入射偏振是否满足相位调制要求；
- SLM 面、测量面和校正共轭面的关系；
- 相机—SLM 坐标映射、旋转、缩放和有效孔径；
- 参考臂漂移、相位展开和模 \(2\pi\) 处理方式；
- 振幅闪烁是否强到无法只靠相位补偿；
- 相机型号、帧率、曝光和触发方式；
- 是否有独立焦平面相机或功率计。

H0 没完成前，不设定控制频率，也不选择 PPO 或 SAC 的实物采样预算。

**H0-E：独立评价分流。** 有独立评价通道，才允许把“成像、聚焦或传输改善”写成主要结论；没有时，研究结论降级为波前残差控制。

### H1：确认 SLM 真的能按预期改变光场

依次加载已知的倾斜、离焦和像散相位，检查全息重建中的相位变化：

- 方向是否正确；
- 幅值是否近似正确；
- 不同灰度是否单调；
- 相位查找表在当前波长、偏振和温度下是否有效；
- 相机与 SLM 的坐标映射和校正符号是否正确；
- 相位展开与 \(2\pi\) 包裹是否产生跳变；
- 各候选模态的响应强度和串扰；
- 显示后需要多久才稳定；
- 重复显示同一图案的波动有多大。

利用这些响应形成 SLM 影响矩阵。根据其可控奇异值和扰动能量覆盖率选择模态数，不预先固定维数。

### H2：不用 RL 先闭合最简单回路

在相位型 SLM、正确共轭面、可靠配准、足够相位范围且闪烁不过强的条件下，测量相位后加载受约束反相位。只有当独立指标或预先声明的残余相位指标稳定改善，才证明“测量—计算—SLM—再测量”链路有效。直接反相位不是所有光路中的解析最优解。

### H3-A：确认动态问题确实存在

记录连续时间戳，比较：

- 扰动变化时间；
- 相机曝光和传输时间；
- 全息重建时间；
- 控制器推理时间；
- SLM 传输和稳定时间。

如果一个控制周期比扰动变化还慢，不能声称实时大气湍流补偿。此时可以先研究慢变化像差或时间放慢的硬件在环相位屏。

### H3-B：用外部激励识别动作的因果作用

普通闭环数据中，“动作”总是由“过去观测”决定，模型可能只记住湍流相关性，却没有学会 SLM 动作真正造成了什么。RL 前必须：

- 在已验证安全范围内发送随机模态探针、伪随机序列或多正弦小扰动；
- 提前生成扰动序列，但对控制器隐藏；
- 随机化不同控制器的运行顺序，减少温漂和时间趋势偏差；
- 分开记录“控制器想要的动作”“实际发送图案”“稳定时间”和“动作后观测”；
- 把一组完整扰动序列封存，不参与模型选择或调参。

这些是系统辨识数据，不是 RL 探索奖励数据。

### H4：建立安全数据采集与回退

每一帧必须保存：

- 动作计算时刻；
- 实际发送给 SLM 的图案；
- SLM 稳定或预计稳定时刻；
- 动作前后观测；
- 是否饱和、丢帧或重建失败；
- 回退控制器是否接管。

动作越界、重建失败或指标突然恶化时，回到厂商允许范围内的**最后一个已验证安全图案**或已验证经典控制器。零相位不自动等于最安全状态。

### H5：先导决策与测试封存

H0—H3 的数据只用于硬件摸底、模型选择和算法决策。按照第 1 节决策树选定：

- 主要指标；
- 一个主要算法对比；
- 模态数和动作范围；
- 统计方法和停止规则。

随后冻结代码、超参数与分析计划，再打开 H3-B 封存的测试扰动。测试结果不能反过来用于继续选择算法。

### 单块 SLM 的结论边界

如果同一块 SLM 同时显示“人工湍流 + 校正相位”，可以做硬件在环验证，但论文必须称为：

> **单 SLM 硬件在环概念验证。**

它不能证明系统已经补偿了独立传播产生的真实大气湍流。更强的实物证据应让 SLM 只负责校正，扰动来自独立相位板、热空气或其他物理路径。

若只能使用单 SLM，扰动生成程序与控制器必须分进程或分权限隔离；控制器不能读取真实扰动系数，只能看到实验允许的测量。

## 11. 推荐的最小比较与反事实实验

### 11.1 核心比较与诊断比较

核心结果至少包括：

1. 条件成立时的直接相位共轭、Zernike 拟合或约束投影；
2. 调到最优的逐模态泄漏积分器；
3. 数据驱动线性预测控制或 LQG/MPC；
4. **同一非线性动力学模型 + 受约束 MPC 或轨迹优化**；
5. **同一非线性动力学模型 + PO4AO 式 RL 策略**；
6. 残差 SAC。

诊断比较包括 SPGD 或其他单步黑箱优化，以及 `折扣因子 = 0` 的单步 RL。Zhang 等（2026）<!--ref:zhang2026sdrl--><!--anchor:doi:10.1016/j.optlaseng.2026.109740-->已经表明单步 RL 可完成实物 SLM 波前整形，因此多步 RL 必须证明自己的时间价值。PPO 先作为仿真补充，不占用首轮 SLM 实物采样。

### 11.2 公平比较规则

公平不是把所有控制器故意拖到一样慢。应匹配：

- 相同的训练和验证扰动；
- 相同的观测与动作维数；
- 相同的动作硬约束；
- 相同的真实系统数据访问与封存测试序列；
- 预先声明且可比的调参协议；
- 核心孪生对照共享同一编码器、动力学模型和基础控制器。

训练计算、模型内模拟数据、内存、原生部署延迟和墙钟时间分别完整报告，不强行做成相同。结果同时画出“性能—真实交互量—延迟—计算成本”的权衡；快速经典方法保留其真实速度优势。不能让 RL 看更多真实序列，也不能给 RL 历史信息却只给经典控制器单帧。

### 11.3 三个反事实检验

1. **无未来检验**：把折扣因子设为零，只允许策略关注即时结果；
2. **时间打乱检验**：保留数值分布，但打乱历史帧顺序；
3. **动作历史删除检验**：不告诉策略前几帧 SLM 实际加载了什么。

如果三种修改都不影响性能，不能声称控制器学会了动态预测。

### 11.4 成功与停止规则

先用独立先导运行估计系统重复性，再根据物理意义和测量精度预注册“最小有意义改进”。不预设通用的 5% 规则。

- 实验单位是**独立扰动序列或独立运行**，不是相关的视频帧；
- 用先导方差做样本量或精度规划；
- 预先固定一个主要指标和一个主要算法对比；
- 时间自相关使用分块自助法、层级模型或其他适合时序的数据方法；
- 多方法、多条件属于次要比较，并进行多重比较控制；
- 主要差值置信区间的下界应超过预注册最小有意义改进，而不只是超过零。

认为 RL 值得继续的条件：

- 主要指标的改进超过预注册阈值；
- 配对置信区间下界超过预注册阈值；
- 优势出现在未见扰动和标定、时延失配条件；
- 违规、失败和回退率没有增加；
- 时间打乱或删除动作历史后优势明显下降。

停止或转向的条件：

- 非线性动力学模型不能超过线性预测；
- RL 的增益小于重复性噪声；
- 强经典预测控制表现相同但更快、更稳；
- 优势只存在于训练扰动；
- SLM 速度不足以形成有意义的动态闭环。

## 12. 方法学建议

### 12.1 数据拆分

不要随机打散相邻视频帧。按整段扰动序列划分训练、验证和测试，避免相邻帧泄漏。额外保留三类完全未见条件：

- 新的扰动强度或速度；
- 新的光强和噪声；
- 新的 SLM 查找表偏差、配准误差或时延。

控制器运行次序要随机化或平衡化，防止某个方法总是在设备刚开机或温漂更小的时段测试。

### 12.2 统计报告

至少报告：

- 独立扰动序列或独立运行的数量；
- 样本量或精度规划依据；
- 多次独立重复的均值和置信区间；
- 每段时间序列的配对差值；
- 时间自相关和多重比较的处理方法；
- 稳态性能、收敛时间和最坏情况；
- 动作总变化、饱和次数、失败率、回退率；
- 端到端延迟的中位数、95 分位数和抖动；
- 训练帧数、调参预算和部署推理时间。
- 训练计算、模型内模拟数据量、内存占用和墙钟时间。

### 12.3 术语边界

- 全息系统能重建相位时，应称“**无传统波前传感器**”或“**全息辅助波前测量**”，不宜笼统称“完全无传感器”。
- 同一 SLM 生成扰动并校正时，应称“**硬件在环**”，不称“独立物理湍流闭环”。
- ResUNet 当前是静态监督相位估计器，不是强化学习策略，也不是闭环证据。

## 13. 局限

1. 当前语料由 Phase 2 的 28 项重点来源和 Phase 3 的 4 项定向最近邻组成，但不是系统综述，也没有穷尽专利、中文数据库和所有会议摘要。
2. SLM 实物 RL 和数字全息复场 + SLM 补偿均已有直接先例；尚可研究的只是更窄的“离轴全息时序观测下的 RL 独立增量价值”，仍不能使用“首次”措辞。
3. 多数论文没有在相同硬件、相同观测和相同预算下比较，算法排序只能视为条件性证据。
4. 已知实验室有两台 `FSLM-2K73-P04`，但实际激光波长、两台设备的位深、LUT、刷新稳定时间和完整动作范围仍须 H0—H1 实测，因此控制频率和采样量不能只按厂家标称值确定。
5. 现有真实数据缺少动作—响应和严格时间戳，不能支持闭环因果结论。
6. S29 与 S30 是同一团队和相近实验平台，PO4AO 多篇来源也属于连续技术链；论文数量不能直接解释为独立复现次数。
7. 定向新增的四个 DOI 已核对出版者页面，检索日未见撤稿、关注声明或更正标记，但这不替代日后的 Crossmark 和全文复核。
8. Phase 3 的综合和判断由 AI 辅助完成；`scholar_confirmation` 仍为 `pending`，关键创新措辞在投稿前应由研究者再次查重和逐篇复核。

## 15. Phase 3 交接结论

### 已确定

- 主问题不是“能不能用 RL”，而是“在测得相位的 SLM 闭环中，RL 策略是否比共享同一模型的非 RL 规划器多带来价值”。
- SLM 实物 RL、数字全息 + SLM 和实物 SLM 波前整形 RL 均已有直接近邻，不能作为创新本身。
- 算法不提前锁定；只有先导数据表明非线性模型必要时，才比较同模型 MPC 与 PO4AO 式策略。
- 残差 SAC 是第二候选；PPO 先留在仿真；复杂循环记忆要等历史检验证据。
- 必须比较条件成立时的直接相位补偿、调优积分器、线性预测控制、同模型非 RL 规划和单步控制。
- 真正可能形成贡献的是严格识别时序 RL 的独立增量，而不是硬件或算法名称。
- 硬件采用两台 `FSLM-2K73-P04`：SLM-A 负责隐藏扰动，SLM-B 负责补偿；另有光功率计。
- 执行顺序改为纯仿真 S0—S4 与硬件 H0—H1 并行，冻结策略后再迁移。

### 尚未确定

- 实际激光器型号、工作波长和安全工作功率；
- 相机型号、感光波段、帧率、曝光和触发方式；
- 光功率计主机及探头型号，以及是否有焦面选择元件；
- 两台 SLM 的序列号、实际位深、厂家校正文件、LUT 和稳定时间；
- 实测动力学是否复杂到需要非线性模型；
- 精确的窄空缺能否经专利、会议和投稿前定向检索进一步确认。

### 下一阶段的两个入口

电脑端可以立即进入纯仿真 `S0`，不必等待全部硬件信息：先修复 MATLAB 传播并建立物理单元测试。

实验室端继续完成 `H0`：补齐激光器、相机、功率计探头、两台 SLM 序列号和校正文件信息，再进入 H1 标定。
