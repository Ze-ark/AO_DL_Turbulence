# 项目总览

本项目用于做深度学习辅助自适应光学湍流补偿。当前路线是先用 MATLAB 生成有标签仿真复光场数据训练模型，再用真实离轴全息实验数据导出的复光场做验证。

## 当前目标

模型输入为湍流复光场的强度和相位：

```text
[normalized_intensity, wrapped_phase]
```

模型输出为补偿相位：

```text
phi_corr
```

训练时显式计算补偿后复光场：

```text
E_comp = E_turb * exp(-1j * phi_corr)
```

然后用 `E_comp` 对齐无湍流高斯光目标 `E_clean`。

## 数据分工

```text
仿真数据：训练集 + 测试集
真实实验数据：验证集
```

仿真数据有 clean target，因此可以计算监督损失和复场误差。真实实验数据目前没有无湍流真值，因此用于观察模型在真实复光场上的补偿相位、光斑质心漂移和分温差统计。

## 主要目录

```text
configs/      训练、测试、真实验证配置
matlab/       MATLAB 仿真和真实复光场导出脚本
src/          PyTorch 数据集、模型、训练、评估代码
tests/        自动化测试
data/         HDF5 数据文件，Git 忽略
checkpoints/ 训练权重，Git 忽略
outputs/     训练日志、评估图、指标表，Git 忽略
```

## 主要入口

训练：

```powershell
.\.venv\Scripts\python.exe -m src.train_compensation --config configs\sim_gaussian_v1.yaml
```

仿真测试评估：

```powershell
.\.venv\Scripts\python.exe -m src.evaluate_compensation --config configs\sim_gaussian_v1.yaml
```

真实实验验证：

```powershell
.\.venv\Scripts\python.exe -m src.validate_real_experiment --config configs\sim_gaussian_v1.yaml
```

## 当前限制

真实验证集不是监督测试集，因为没有真实无湍流复光场标签。真实验证指标只能说明模型在真实数据上的输出分布和光斑统计变化，不能直接等同于补偿精度。
