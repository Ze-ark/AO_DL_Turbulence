# 项目总览

本项目研究离轴数字全息观测下的自适应光学补偿。当前主线不是直接在真实 SLM 上训练强化学习，而是：

```text
修复纯仿真 → 建立动态闭环 → 做强传统基线 → 测试 RL 的额外价值
→ 加入真实硬件误差 → 双 SLM 影子测试与硬件在环 → 独立物理扰动
```

## 必用研究技能

本项目所有任务必须先使用已注册的 `academic-research-suite`：完整读取入口 `SKILL.md`，再根据任务只进入一个匹配的工作流，不允许静默跳过，也不应一次性加载整个技能库。

常用路由如下：

| 项目任务 | 使用的工作流 |
|---|---|
| 实验设计、运行、基准测试、结果统计和复现 | `experiment-agent` |

| 论文大纲、写作、修改和引用检查 | `academic-paper` |
| 同行评审与审稿意见模拟 | `academic-paper-reviewer` |
| 从研究到论文的完整管线 | `academic-pipeline` |

## 两条并行路线

### 电脑端：纯仿真主线

1. `S0`：修复传播、相位屏、接收面参考和评价指标；
2. `S1`：建立“观测 → 动作 → 下一观测”的动态环境；
3. `S2`：完成直接相位补偿、积分器、LQG/MPC 等传统基线；
4. `S3`：条件满足时比较同模型 MPC、PO4AO 式策略和残差 SAC；
5. `S4`：加入噪声、延迟、量化、饱和、LUT 偏差和配准误差；
6. `S5`：冻结策略后进入真实系统影子测试。

### 实验室端：双 SLM 标定

1. `H0`：查清两台 SLM、激光器、相机和功率计探头的信息；
2. `H1`：分别测量两台 SLM 的灰度—相位关系、稳定时间和空间校正；
3. `H2`：不用 RL，先证明 SLM-A 制造的已知扰动能被 SLM-B 稳定抵消；
4. `H3`：测量真实动作—响应时序，并判断系统是否存在可利用的动态规律。

纯仿真和 H0—H1 可以并行推进。H1 的实测参数以后用于替换仿真中的假设范围。

## 算法怎么选

算法不按名字预先锁定：

- 没有时间规律：不做 RL，使用静态校正；
- 线性模型已经足够：优先使用 LQG 或 MPC；
- 非线性模型稳定优于线性模型：比较“同一非线性模型 + MPC”和“同一模型 + PO4AO 式策略”；
- 残差 SAC 作为第二 RL 候选；
- PPO 先只做纯仿真补充。

RL 必须在相同观测、动作约束、训练数据和测试扰动下，与强传统方法公平比较。

## 现有静态模型

当前 ResUNet 输入为：

```text
[normalized_intensity, wrapped_phase]
```

输出为：

```text
phi_corr
```

现有代码使用：

```text
E_comp = E_turb * exp(-1j * phi_corr)
```

这一流程保留为静态基线和软件冒烟测试，但它不是动态闭环，也不能单独证明焦平面性能改善。
