# S4-D2-R4-1B2-D2 候选动作独立确认审计记录

## 结论

48个全新天气的局部八步确认通过全部预声明门槛，允许设计完整闭环确认，但不放行强化学习。桶内功率相对零修正的局部增益约为0.0902%，仍不能声称达到完整闭环的1%实用门槛。

## 完整性

- 48个天气、18个批次和1,152个探测状态完整。
- 79,488次物理转移和640,687,104次模型前向与预算一致。
- 4,576个冻结来源、25个产物和18个分支文件哈希通过。
- 原始分支重算的动作选择0处不一致；目标最大差为单精度尾数`9.54e-7`。
- 无训练、无SLM动作、无失败标记或自动重试。

## 主结果

- 八步审计目标收益：0.001111，95%分层区间为[0.000399, 0.001871]。
- 桶内功率差：0.000656；Strehl差：0.000591。
- 违规率差：0.0000124；残差相位均方根误差差：-0.000679。
- 非零动作率：63.98%；三类湍流平均目标收益均为正。

相对原规划器时，综合目标提高但桶内功率和Strehl略降，说明部分收益来自减少动作代价。该辅助结果不能解释为光学性能优于原规划器。

## 统计边界

统计单位为完整天气，六档和四个探测时刻先在天气内平均。11类统计谬误检查全部完成；未发现推翻主结论的问题，但存在效应很小和部分家族—档位目标异质性的谨慎项。验证状态为`ANALYZED`，没有重新运行整场正式仿真。

## 授权边界

仅允许冻结当前规则，在另一批全新天气上进行完整200帧闭环确认。不得根据D2结果调整阈值、候选或模型，不得声称RL有效，不得连接真实SLM。
