残余模态项不能四舍五入成“已经达到5%”；功率项也不是接近5%。三个成员的8步误差都朝改善方向变化，但幅度不足。该门槛是工程筛选标准，不是显著性检验；本次没有新增置信区间或p值，不能称“显著改善”或“统计上证明无效”。

| 生态谬误 | 仅解释当前仿真开发轨迹的模型平均误差，不外推单回合、硬件或自然大气 |
| 伯克森偏差 | 按既定闭环采集器采样，代表其状态分布，不代表所有控制器可达状态 |
| 碰撞变量偏差 | 未按结果删回合或追加条件筛选；不作原因唯一性判断 |
| 基准率忽视 | 连续误差指标，不适用分类基准率解释 |
| 均值回归 | 使用等更新量旧数据对照，不仅比较修复前后 |
| 幸存者偏差 | 保留中断、失败恢复及计算成本；不只报告成功执行的部分 |
| 多重尝试 | 两项预先规定的门槛全部报告，不改挑其他预测时域 |
| 岔路花园 | 固定最终2,000批模型、5%门槛和停止条件；不追加第二轮修复 |
| 相关与因果 | 干预同时改变独立天气与状态覆盖，不能将收益全部归因于分布漂移修复 |
| 反向因果 | 训练先于独立评价；预测误差改善不能反推闭环收益已改善 |
