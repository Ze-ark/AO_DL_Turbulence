## 1. 研究决策摘要

当前系统条件是：

- 离轴数字全息重建复光场；
- 两台中科微星 `FSLM-2K73-P04` 相位型反射式 SLM；
- SLM-A 计划生成对控制器隐藏的扰动；
- SLM-B 计划执行补偿；
- 光功率计可在焦面选择支路提供独立评价；
- 暂无可变形镜和传统波前传感器。

主问题不再是“RL 能不能控制光学器件”，而是：

> 在离轴全息连续观测和真实 SLM 约束下，RL 策略是否比共享同一观测、动力学模型和安全约束的非 RL 规划器带来可重复的额外时序价值？

研究采用纯仿真优先、双 SLM 迁移的顺序：

```text
物理正确的 MATLAB 参考仿真
→ GPU 动态闭环环境
→ 强传统基线
→ 条件性 RL 比较
→ SLM 数字孪生与域随机化
→ 影子运行
→ 双 SLM 硬件在环
→ 独立物理扰动
```

任何一层未通过门槛，就停止向下一层增加复杂度。

## 3. S0：物理与统计 Gate 0

### 3.1 当前阻断问题

1. 同一平面只减相位不会改变该平面光强，现有部分焦面类指标对动作不敏感；
2. MATLAB 代码在频域变量上直接乘空间相位屏，并跳过第一块相位屏；
3. 当前 `r0_or_equivalent` 只使用单段距离，不能解释为完整路径 Fried 参数；
4. 无湍流目标来自源平面，而湍流输入位于传播后的接收面；
5. 完整无噪声相位加理想相位型执行器会把任务退化为近似直接相位共轭；
6. 当前测试数据参与选模，存在测试泄漏；
7. 当前真实数据没有动作、动作后观测和同步时间戳。

### 3.2 S0 通过条件

以下全部通过后，才创建正式动态数据：

- 空间相位屏与频域传播按 split-step 规则交替执行；
- 所有相位屏都实际参与传播；
- 使用完整路径定义 `r0`，每个场景包含多个独立随机种子；
- 无湍流参考场经过相同传播链到达同一接收面；
- 增加瞳面、SLM 动作和瞳面到焦面传播；
- 动作对焦点功率、Strehl 或环围能量具有非零且方向合理的影响；
- 零湍流、能量守恒、结构函数、理想相位共轭、饱和、延迟和随机种子复现测试通过；
- 相位误差只在有效瞳面内计算，并移除 piston；
- 训练、验证和测试按完整场景与回合隔离；
- 旧 checkpoint 只保留为冒烟产物。

## 4. Research Question Brief

### 4.1 主研究问题

> 在通过 S0、具有连续湍流、测量噪声、控制延迟、SLM 量化、相位范围和模型失配的动态闭环中，“同一非线性动力学模型 + PO4AO 式策略”是否相对“同一模型 + 受约束 MPC 或轨迹优化”，提高封存扰动上的时间平均焦平面质量，同时不增加违规、失败和回退率？

### 4.2 子问题

1. 历史观测是否比单帧观测提供可重复的预测价值？
2. 非线性动力学模型是否稳定优于线性 VAR、子空间模型或保持上一帧？
3. RL 的收益是否来自策略本身，而不是更大的模型、更多数据或更宽动作范围？
4. 优势能否迁移到未见噪声、延迟、LUT、配准和扰动条件？
5. 仿真优势能否在双 SLM 硬件在环中保持正确方向？

### 4.3 可证伪条件

以下任一情况会削弱或否定 RL 主张：

- 打乱时间顺序后性能不下降；
- 删除动作历史后性能不下降；
- 非线性模型不优于线性模型；
- 共享模型的 MPC 与 RL 表现相同但更快、更稳定；
- RL 只在训练扰动有效；
- 改善幅度小于仿真或硬件重复性波动。

## 5. 动态环境契约

### 5.1 状态

仿真内部状态包括：

- 连续演化的湍流相位屏；
- SLM-A 扰动状态；
- SLM-B 液晶、量化和延迟队列；
- 传播光场；
- 相机曝光、噪声和重建状态；
- 配准、温漂和光强漂移。

完整状态只供仿真器使用，不能全部泄漏给策略。

### 5.2 观测

首轮策略观测使用：

- 全息重建得到的低维相位模态；
- 少量振幅、闪烁或光强特征；
- 前几步实际加载的 SLM-B 命令；
- 时间戳、丢帧和未稳定标记。

完整复光场可以作为教师和诊断输入，但主要对比中的所有控制器必须获得相同观测。

### 5.3 动作

动作是 SLM-B 的低维模态增量：

```text
delta_u_t → 安全投影 → 量化/LUT → 实际相位图
```

模态数由 H1 影响矩阵的可控奇异值、串扰和扰动能量覆盖率决定，不预设 8、15、36 或其他固定数值。

硬约束包括：

- 总相位范围；
- 单步变化范围；
- 模态系数范围；
- 空间相位梯度；
- 位深量化；
- 饱和和回退条件。

### 5.4 转移

```text
冻结流或带沸腾湍流
+ SLM-A 隐藏扰动
+ SLM-B 动力学和延迟
+ 光学传播
+ 相机形成与重建
→ 下一观测
```

### 5.5 奖励与主要指标

候选训练奖励：

\[
r_t = w_1 Q_{\mathrm{focus},t}
- w_2 E_{\mathrm{phase},t}
- w_3 \lVert \Delta u_t \rVert_2^2
- w_4 I_{\mathrm{violation},t}.
\]

权重只在开发集调整。正式主要指标独立定义，优先为时间平均归一化焦点功率、Strehl、环围能量或耦合效率。

## 6. 控制器比较

### 6.1 必须包含的基线

1. 不校正；
2. 条件成立时的理想相位共轭上限；
3. 受约束相位投影或正则化最小二乘；
4. 调优后的泄漏积分器；
5. 线性预测、LQG 或 MPC；
6. 当前或重训后的 ResUNet 静态基线；
7. 同一非线性动力学模型 + 受约束 MPC 或轨迹优化；
8. 同一非线性动力学模型 + PO4AO 式策略；
9. 残差 SAC；
10. 单步控制、时间打乱和删除历史对照。

PPO 只作为纯仿真补充，不占用首轮真实 SLM 采样预算。

### 6.2 公平比较

所有方法共享：

- 相同训练、验证和测试扰动；
- 相同观测、动作维数和动作硬约束；
- 相同可访问的真实系统数据；
- 相同动力学模型和特征编码器，用于核心孪生对照；
- 预先声明的调参协议。

分别报告环境交互量、总计算量、推理延迟和显存，不把快速控制器人为拖慢。

## 8. 仿真到真实迁移

### 8.1 域随机化参数

- 湍流强度、风速、风向和非冻结成分；
- 相机噪声、曝光、增益和丢帧；
- SLM 位深、LUT、相位范围、迟滞和稳定时间；
- 坐标旋转、缩放、平移和光瞳裁剪；
- 0—3 帧延迟；
- 光功率计或焦面评价噪声。

未知量使用保守范围，H1 后替换为实测分布并保留一部分失配作为测试。

### 8.2 迁移顺序

1. 冻结策略、特征、动作范围和分析计划；
2. 用真实观测做影子运行，只记录动作；
3. 检查越界、饱和、抖动和回退；
4. SLM-A 播放对控制器隐藏的安全扰动；
5. SLM-B 从很小残差动作开始；
6. 比较相位指标和焦面选择功率；
7. 最后加入热空气或相位板等独立扰动。

首轮真实系统禁止 RL 自由在线探索。真实微调优先更新动力学模型或使用离线数据，并重新通过影子门槛。

## 9. 数据、统计与复现

1. 动态数据按完整回合拆分，不能随机拆散相邻帧；
2. 所有控制器在相同封存轨迹上做配对评价；
3. 策略随机种子是主要独立复现单位，回合数不能替代策略复现；
4. 先导阶段使用 3—5 个开发种子估计方差；正式种子数由先导方差和精度规划决定；
5. 报告均值、中位数、95% 置信区间、配对效应、最差十分位和失败数；
6. 多个次要指标使用多重比较校正；
7. 真实连续序列使用时间分块方法，不能把每帧当独立样本；
8. 保存 Git 提交、配置快照、数据哈希、场景划分、依赖版本、随机状态、逐步指标、墙钟时间和失败日志；
9. 确定性实验要求完全复现；随机实验使用预注册容差。

## 11. 风险和停止规则

| 风险 | 处理方式 |
|---|---|
| 策略利用仿真漏洞 | 物理测试、独立指标和跨实现对照 |
| 完整相位让任务退化 | 强制比较直接相位投影和 MPC |
| 模态数没有硬件依据 | 用 H1 影响矩阵和扰动能量选择 |
| 真实数据无动作响应 | 只做影子检查，另采集时序轨迹 |
| 奖励改善但科学指标不改善 | 奖励与主要指标分开 |
| RL 被 MPC 稳定击败 | 接受负结果，转向预测控制或系统辨识 |
| SLM 太慢 | 转向慢变化像差或时间放慢的硬件在环问题 |
| 安全动作越界 | 硬投影、影子运行和经典回退 |

RL 值得继续的条件：主要指标改进超过预注册阈值，置信区间下界也超过该阈值，且未见条件、违规率和时间反事实检验同时通过。
