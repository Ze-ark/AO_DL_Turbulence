## 与项目最相关的优先阅读顺序

1. 先读 05，理解为什么“单帧或开环预测好”在闭环中可能失败。
2. 再读 09 和 04，建立不依赖强化学习的预测控制对照。
3. 再读 02 和 03，了解模型式强化学习怎样从仿真走向实验台。
4. 最后读 13、14 和 16，对照功率计、SLM、SAC 和多智能体路线。
