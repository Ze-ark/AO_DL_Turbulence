# S4-D2-R2 模态分解诊断审计记录

## 结论

正式模态分解诊断完整结束，结果可信。现有SAC策略的主要损失几乎全部来自第11维以后的新增高阶动作；前10维动作单独使用时与冻结传统控制器非常接近，没有证据表明它会稳定改善或稳定破坏系统。

21维策略只保留新增11维时，桶内功率平均下降11.4515%；36维策略只保留新增26维时，平均下降65.8009%。两种表示的3个策略种子置信区间上界都低于0，而且所有54个“策略种子×硬件档位×动态条件”组合均为负收益。相反，只保留前10维时平均变化分别为-0.0242%和-0.1942%，置信区间都跨过0。

因此不能把程序给出的`BOTH_ACTION_SUBSPACES_DESTRUCTIVE`字面标签直接当作统计结论。更准确的表述是：**新增高阶策略动作具有稳定破坏性，前10维策略动作与传统基线近似等效。**

## 可以和不能说明什么

可以确认：

1. 现有6个SAC策略的新增高阶输出具有跨种子、跨硬件档位和跨动态条件的一致负效应；
2. 前10维RL输出不是R2大幅失败的主要来源；
3. 21维比36维更容易控制，但现有21维策略仍明显失败；
4. 下一步应先验证“高阶子空间本身是否存在有用动作”，而不是直接增加训练量或更换算法名字。

尚不能确认：

- 高阶动作失败来自高阶观测不可辨识、标量奖励信用分配困难、SAC优化不稳定，还是动作合成方式；
- 只训练新增高阶维的新策略是否能够成功；
- PPO、TD3或其他算法是否优于SAC；
- 仿真结论是否适用于真实SLM或自然大气。
