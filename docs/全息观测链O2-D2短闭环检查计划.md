# O2-D2：给闭环加上读出噪声，先检查能否安全跑通

这一步不是训练，也不是新一轮收益验收。把 D1 中仍可读取的四档噪声接进动态闭环，检查“拍图 → 读相位 → 发动作 → 等延迟 → 再拍图”是否正常。模型保持不变；只有人工相机读出噪声标准差变化。准备证据见 [准备验证记录](全息观测链O2-D2准备验证记录.md)，D1 依据见 [完成审计](全息观测链O2-D1完成审计记录.md)。

## 研究问题与假设

- 问题：加入 0、0.001、0.3、1 四档人工噪声后，合法图像读数、动作/功率时序、历史观测与冻结模型决策能否稳定完成短回合，并从保存的可见记录重放？
- 待检验假设：固定范围内能完成所有事前指定短回合，观测质量达到技术目标，模型重放一致。动态条件仍可能出现 D1 没有出现的拒绝，不预先保证通过。
- 选择这四档依据 D1，不选择已知大部分拒绝的 3、10 档来持续驱动控制；本轮是开发技术检查，非事前盲测鲁棒性确认。
- 干扰因素：同模生成与重建的理想化、天气、模型初始化、打分器折、读数保护与负强度裁剪。天气与相机随机流配对，初始化全部保留，光学/执行参数不变。

## 固定预算

| 项目 | 完整检查 |
|---|---|
| 天气基种子 | 8600000、8600010、8600020、8600030 |
| 天气类型 | 冻结平移、局部演化、随时间变化，共 3 类，CUDA 批量 3 |
| 人工噪声 | 0、0.001、0.3、1，任意合成强度单位，未标定真实相机 |
| 控制分支 | 积分器 1；原策略 3 初始化；当前策略与打分器组合 9，共 13 |
| 打分器 | 天气索引对 4 取余分配折，提前固定；12 份权重与保存归一化器，不重新拟合 |
| 单回合长度 | 32 帧；第 25 帧起重选，共实际调用 7 帧 |
| 完整回合 | 4 天气 × 4 噪声 × 13 分支 × 3 类型 = 624 |
| 仿真物理转移 | 19,968，208 批完整回合，6,656 次批量步 |
| 模型调用 | 策略 6,144 次；打分器 1,008 次；可见记录重放另有相同调用，新增环境转移为 0 |
| 相机抽样 | 6,864 次批量抽样，20,592 次类型/帧抽样，含初始观测与零噪声 |
| 配对前缀检查 | 144 次，重选启用前动作与图像观测逐值一致 |

624 回合不等于 624 份独立天气。这里只覆盖 4 份新天气，每折一份，用于接口检查；不生成收益排名、置信区间或显著性检验。

积分器 gain（增益）0.15、leak（泄漏系数）0.10；策略尺度 1.75；候选扰动 0.1；候选共 25 个，打分预测 23 个加两个固定零分候选。执行器仍是标称合成参数：2 帧延迟、256 档量化、每步最大相位变化 0.35 弧度。不是两台真实 SLM 的实测参数。

## 输入与信息隔离

- 必须校验封存 C1 源码/模型、O2-A/B/C、D1 完整与快速输出的指纹；不可调用它们的运行入口，或读取旧确认轨迹重新调参。
- 图像来自当前完整瞳面复场，不先投影成 21 模态；人工离轴全息生成、重建和 GPU 相位读取复用封存实现。
- 同天气、同类型、同帧在全部控制分支与噪声档使用相同标准正态随机数。即使零噪声仍抽样，包含初始帧，不因算法选择改变抽样量。不同类型独立随机流。
- 策略只接收相机产生的历史白名单特征与有效历史掩码；真值、Strehl（峰值光强质量指标）、硬件标签、未来帧和当前审计误差不传入模型。
- 独立模拟功率计给出已完成动作的桶内功率，按动作时钟到达下一观测；不拿图像亮度或下一帧真值冒充动作奖励。
- 真值只用于生成图像、事后采样前提核验和隔离审计。噪声误差不得补回、修正或筛选控制动作。
- 保持数据格式不变，新增的是本诊断输出，不是 MATLAB 真实 HDF5 数据。

## 技术判定与停止条件

必须完成固定网格，无失效、无截断、无暗中跳过；完整预算一致，候选/掩码/时钟重放完全一致，浮点重放最大误差不超过 `1e-6`。零噪声最大模态误差不超过 0.001 弧度。沿用 C 的技术观测目标：各有噪声档平均均方根误差不超过 0.01、95% 分位数不超过 0.02 弧度。

这些是观测链技术目标，不是 RL 收益门槛。噪声质量目标未达时只记录 `targets_met=false`，不能用真值改善读数；整体完成状态也不自动等于质量通过。

低强度、采样相位跳变、相位环路不一致、非有限数、设备/时钟错误、采样前提失败均立即停止整个运行。保留原报错、已完成轨迹及当前未完成回合 `partial/`、最后已发请求和精确转移计数；不生成 `SUCCESS.json`，不补零、不丢回合、不重试、不换种子。D1 是静态扫描允许记录保护拒绝继续扫描；D2 是闭环，不能带着失效读数继续发动作。
