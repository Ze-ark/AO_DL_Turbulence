# R4-1B2传统候选与小型物理闭环

结论：18组传统候选的定义、请求端回退以及192次转移的小型物理闭环已实现并检查。软件链路通过，但执行器审计有非零限幅，不能称为“零违规安全通过”。未选择最强基座，未进行正式算法比较，未重训模型。

## 已固定的候选

记当前残余观测为r、累计请求为q、名义执行器估计为e。三者均来自白名单接口，不使用真实已加载相位。

- 积分器：请求增量为 `-leak*q - gain*r`。
- 因果跟踪积分器：在积分器上加 `0.5*(e-q)`。
- 岭回归预测控制：用3份原冻结线性模型分别在同参数跟踪积分器的零修正续推下预测2步，取未来残余均值r_hat；实际请求为 `-leak*q - gain*r_hat + 0.5*(e-q)`。预测提前量是名义2步，不偷用隐藏档位的实际延迟。

每类gain取0.15/0.25/0.35，leak取0.05/0.10，共18组；所有实际动作通过相同的原21模态投影。岭回归不重新拟合，不读取开发数据作为训练材料。候选定义在 `configs/experiments/s4_r4_baseline_safety_v1.yaml` 中冻结。

本次只检查每类gain=0.25、leak=0.10的一组，另加同一采集跟踪基座上的R1模型预测控制（MPC）。MPC沿用原128候选、4轮、8步、3模型规模。该临时基座不是已选出的最强传统控制器；当前MPC接口尚不支持把选中的岭回归基座带入所有模型内续推，因此不能直接用本冒烟入口运行正式比较。

## 范围检查与回退

从原R4-1A训练清单的288份轨迹、384条训练天气读取有效观测，残余每模态绝对最大值及已到达功率最大值乘1.25，分别设0.02 rad及0.001的基值下限。开发/确认数据不参与。`calibration.json` 保存来源及阈值。

这是训练观测范围的启发式检查，不是置信覆盖保证或真实硬件校准：

1. 非有限当前历史、无效当前帧、非法补零或不可行累计请求：立即停止，不构造虚假观测继续控制。
2. 有效历史超出校准范围：不调用MPC搜索，撤销额外修正，仍执行传统跟踪基座。
3. 额外修正含非有限值或超过归一化[-1,1]：逐回合退回零修正，其余合规回合不受影响。
4. 规划器内部预测失效：当前实现停止并保留错误，不静默捕获所有异常、重试或改用真值。完整部署回退仍需要进一步验证。

单元测试注入了上述故障并检查退回动作精确等于零修正传统请求。本次自然冒烟未触发范围回退；这不等于已经验证所有物理故障场景。

## 不能忽略的执行器限幅

保存的 `violation_fraction` 是模态限幅比例、像素相位饱和比例和像素变化率受限比例的最大值，不是“回合失败概率”。原R4完整门槛比较的是相对传统基座的平均违规率增加，不是把单步最大值直接与0.1个百分点比较。

本次单步最大值5.0049%，出现在积分器路径。为定位来源，只读离线回放了保存请求对应的192个执行器状态转移，未重跑湍流、规划器或环境；回放实际模态及综合违规值与保存记录逐项精确相同。这些回放是额外的审计计算，不算新增天气或物理环境交互。

- 所有路径均出现像素变化率限制；R1-MPC单步最大受限比例4.0771%。
- 积分器路径还出现像素相位饱和：nominal最大0.2197%，delay_3最大0.5615%；另外三条路径本次回放饱和比例为0。
- 请求模态受限并不保证合成像素相位不触发限幅。实际执行器约束仍在生效，未发现本次请求绕过约束；不能据此声称真实硬件安全。

原始轨迹保存所有指标和回退理由，不按好坏删除。`predicted_score` 对没有运行MPC的项用NaN及 `predicted_valid=false` 表示不可用，不是有效模型预测出现非有限值。实际审计指标均有限。没有从这个小样本计算功率排名或宣布算法优胜。

## 下一步与预算边界

下一步准备18候选的正式开发筛选入口，由用户在IDE启动，不运行全量MPC。沿用既有96条开发天气、6档位、200步，则候选筛选需要 `18×96×6×200=2,073,600` 次物理转移；其中6个岭回归候选额外需要4,147,200个模型前向样本步。校准、冒烟与最终MPC对照成本分开计数，不回收为训练数据。

在看正式筛选结果前固定选择规则：拒绝有非有限状态或投影后越界的候选；以候选池中原采集跟踪基座（gain=0.25、leak=0.10）为参照，完整开发回合平均实际违规比例增加不超过0.001的候选才可进入选优；合格候选按平均桶内功率排序，同分按配置固定顺序，若无合格候选则停止。此规则仅用于开发选择，不等于独立科学确认。正式实现需冻结种子、选择记录和总预算并提交给用户。

选择完成后，必须把唯一冻结基座一致接入线性MPC、R1-MPC和未来策略的真实及模型内路径，验证零修正退化，再准备完整闭环比较。不能因为本次限幅而自动扩大相位/变化率范围或改写旧实验。

本轮未改物理模型、原模型权重、真实HDF5数据格式或硬件文件。未运行全仓库测试（已运行直接相关R4测试）、MATLAB对照（物理模型未变）、完整开发筛选和真实SLM验证（尚未授权执行）。
