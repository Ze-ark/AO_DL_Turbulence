## 1. 先说结论

`S2` 纯仿真门槛已经通过，结果可以确定性复现。

这里的“通过”是指：动态环境、传统控制器、ResUNet（残差 U 形网络）和统一评价程序都能在同一批封存回合上稳定运行。它**不等于 ResUNet 获胜**，更不等于强化学习或真实 SLM 已经验证。

本轮最重要的发现是：

- 所有可部署控制器都明显优于“不校正”；
- 以预先指定的主要指标“桶内功率”为准，泄漏积分器最好；
- 新训练的动态 ResUNet 能准确估计低阶波前，但闭环结果没有超过强传统控制器；
- 因此下一步不是直接训练强化学习，而是先进入 `S3` 的“非线性模型是否真的比线性预测更有用”门槛。

本轮没有向两台 `FSLM-2K73-P04` 发送图案，也没有使用真实全息观测。

## 2. 小白版：这次到底比较了什么

可以把控制器想成几种不同的“纠错方式”：

1. **不校正**：什么也不做，作为最低参照。
2. **直接投影**：看到当前误差，马上反向抵消。
3. **泄漏积分器**：每次只纠正一部分，并慢慢忘掉旧命令，特点是稳。
4. **线性预测器**：根据最近变化猜下一帧误差，提前补偿时延。
5. **动态 ResUNet**：先从二维波前图中估计应该纠正的低阶形状，再输出与传统控制器相同的十维动作。
6. **理想模态上限**：假设没有时延、量化等限制，瞬间抵消十个可控模态；它只是上限，不是现实控制器。

为了公平，所有方法面对相同的湍流回合、动作范围和评价指标。ResUNet 没有直接读取十维残余模态真值，而是读取统一的二维理想瞳面观测：归一化强度和包裹相位。

## 3. ResUNet 接入分成了两步

### 3.1 旧静态模型直接迁移：失败

先冻结旧模型，不重新训练，把它直接接到动态瞳面观测上。64 个开发回合、每回合 200 步的结果为：

- 模态方向相似度：`0.098`，95% 置信区间 `[0.020, 0.176]`；
- 相对模态误差：`1.106`，95% 置信区间 `[1.029, 1.184]`；
- 迁移门槛：`FAIL`。

原因是输入含义不同：旧模型是在传播后的接收面数据上训练的，而本轮统一接口给它的是理想瞳面波前。这个结果只能说明“旧权重不能直接搬过来”，不能说明 ResUNet 结构本身无效。

### 3.2 在动态瞳面数据上从头训练：通过

随后用互不重叠的完整回合生成训练、验证和感知测试数据，从头训练一个**无时间记忆**的 ResUNet。它每次只看当前帧，不看历史帧，也不是强化学习。

- 训练：64 个完整回合，共 3200 帧；
- 验证：32 个完整回合，共 1600 帧；
- 感知测试：32 个完整回合，共 1600 帧；
- 模态方向相似度：`0.989`，95% 置信区间 `[0.988, 0.991]`；
- 相对模态误差：`0.163`，95% 置信区间 `[0.154, 0.172]`；
- 感知门槛：`PASS`。

## 4. 最终封存比较

最终比较使用首次打开的独立种子 `50000` 和 `60000`，共 64 个完整回合，每回合 200 步。表中数值均为回合平均值。

| 方法 | Strehl | 桶内功率 | 相位 RMSE/弧度 | 违规率 |
|---|---:|---:|---:|---:|
| 不校正 | 0.443 | 0.608 | 1.261 | 0.000 |
| 直接投影 | 0.814 | 0.722 | 0.456 | 0.023 |
| 泄漏积分器 | 0.749 | **0.724** | 0.540 | **0.011** |
| 线性预测器 | **0.818** | 0.723 | **0.452** | 0.023 |
| 动态无记忆 ResUNet | 0.800 | 0.718 | 0.476 | 0.022 |
| 理想模态上限 | 0.836 | 0.726 | 0.421 | 不适用 |

与“不校正”进行同回合配对比较时，桶内功率提升为：

- 直接投影：`+0.114`，95% 置信区间 `[+0.102, +0.126]`；
- 泄漏积分器：`+0.115`，95% 置信区间 `[+0.103, +0.128]`；
- 线性预测器：`+0.114`，95% 置信区间 `[+0.103, +0.126]`；
- 动态 ResUNet：`+0.110`，95% 置信区间 `[+0.098, +0.122]`。

### 怎样理解“谁最好”

- 想让固定小孔或探测器收到更多光：本轮泄漏积分器略好；
- 想让光斑更集中、残余相位更小：本轮线性预测器略好；
- ResUNet 确实有补偿作用，但计算明显更慢，而且没有超过传统控制器；
- 各方法只差几个千分点，不能据此宣称某个算法在所有条件下普遍最好。

## 6. 证据边界

### 已有直接证据

- 单一理想纯仿真条件下，四个可部署控制器均比不校正好；
- 动态无记忆 ResUNet 的感知测试通过；
- 最终比较可以确定性复现；
- Python 全套自动化测试为 `35 passed`。

### 合理推断

- 旧模型失败主要来自训练域和观测平面不匹配；
- 当前强传统基线已经足够接近十模态理想上限，留给复杂方法的提升空间较小。

### 不能声称

- ResUNet、SAC 或其他强化学习优于传统控制；
- 控制器能处理真实离轴全息重建误差；
- 结果适用于真实 SLM、其他湍流强度或自然大气；
- 两台 SLM 已经完成闭环补偿。

当前 MATLAB S1 演示和 Python S2 都使用严格泰勒冻结流，低频子谐波层数为 0。低频子谐波应作为后续跨条件敏感性实验，而不是本次 S2 的阻塞项。

## 7. 下一步：S3 的最小门槛

先训练一个能利用多帧历史的非线性动力学模型，并在新的未见湍流条件上与线性预测器公平比较。只有它持续优于线性模型，才继续比较“同一非线性模型 + 模型预测控制”和强化学习策略；否则保留传统控制器，不强行使用 RL。
