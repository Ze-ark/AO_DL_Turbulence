# O2-D3：相机读数变差后，原方法还能多补偿多少？

结论：保持已有模型和动作限制不变，把 D2 的 32 帧延长到完整 200 帧，比较四档人工读出噪声下的积分器、原强化学习策略和当前动作重选方法。这是新天气上的开发对照，不训练，不是新的独立确认，更不是实际相机或空间光调制器（SLM）实验。

## 研究问题与事前设计

主要问题是：图像测量误差变大后，强化学习（RL）相对冻结积分器的桶内功率增量是否仍保留？同时看 Strehl（聚焦峰值质量）、残差相位均方根误差、动作受限诊断量和推理时间，不能只看功率。

相机只加入一种误差：逐像素零均值高斯读出噪声，之后把负强度裁剪为零；裁剪比例单独报告。标准差固定为 0、0.001、0.3、1，单位是任意合成强度，**没有标定为电子数、实际灰度或真实信噪比**。范围依据开发 D1/D2 确定，不用旧确认天气调参；不再向上搜索到测量拒绝区，也不加入光子噪声、传播误差等其他因素。

| 固定项 | 设计 |
|---|---|
| 新开发天气 | 8 份，种子 `8700000 + 10 × 天气序号` |
| 湍流类型 | 冻结、沸腾、随时间变化；每份天气包含 3 类型 |
| 相机噪声 | 4 档，全部控制分支共享对应的标准正态抽样 |
| 完整回合 | 每条 200 帧，另含初始观测 |
| 积分器 | 增益 0.15、泄漏 0.10、跟踪增益 0.5 |
| 原策略 | 3 次初始化分别闭环；动作力度固定 1.75 |
| 当前方法 | 3 初始化 × 3 打分种子，9 条分别闭环，不集成为一条部署策略 |
| 模型折 | 天气序号除以 4 的余数；每折 2 份天气，观察前固定 |
| 动作重选 | 前 25 帧沿用原策略；之后固定 25 候选、扰动幅度 0.1 |
| 执行器 | 标称合成档：2 帧延迟、256 级量化、0.35 弧度变化限制 |

不挑表现最好的初始化/种子，不改归一化器、观测保护或冻结模型。全部控制器使用同样测量、功率到达时钟、动作约束和天气；模型/采样成本分别记账。合成执行器参数不是两台 FSLM 的实测参数。

## 执行预算

完整开发运行：8 天气 × 4 相机条件 × 13 分支 × 3 类型，共 **1,248 条完整回合、249,600 次物理转移**。CUDA（图形处理器计算）按 3 类型批量运行，共 416 批、83,200 批量步。

- 策略真实前向 76,800 次，打分器 50,400 次。
- 保存可见记录重放有相同模型调用，但新环境转移为 0；这部分时间不能伪装成部署推理延迟。
- 288 次原策略配对前缀检查；83,616 次批量相机抽样，含初始帧和零噪声，合计 250,848 类型帧。
- 正式预检只校验来源、CUDA、种子及 15 份冻结模型；不执行环境或模型前向，不创建正式输出。
- 新种子快速技术冒烟：`8760000`，仅零噪声和标准差 1、28 帧，78 短回合 / 2,184 转移，确保重选实际启用；不输出科学收益或区间。
- 新单元测试保留种子 `8770000..8770999` 及对应传感器、功率、相机偏移流；统计重采样种子 `8790000`。与声明的 G2/C1/B/C/D1/D2、另一 D3 模式互斥。

## 测量和信息隔离

实际反馈路径为：复场 → 人工离轴全息强度图 → 加读出噪声 → 固定裁剪/重建 → 21 模态读数 → 因果历史 → 决策 → 安全投影 → 延迟执行 → 下一图像。策略只使用可见历史和已经到达的功率，不读取相位真值、未来帧、未来功率、安全标签或硬件档位标签。

可见轨迹与真值审计分别存放在 `trajectories/` 与 `audit/`。先保存白名单轨迹、重放动作/预测、检查配对前缀，再做审计统计；真值只用来计算测量误差和科学指标，不替换有噪声读数。

沿用封存观测保护：低强度/空洞、过大相位邻域跳变和相位环路不一致均拒绝。图像生成与重建仍共享理想共轭瞳模型，有“自己出题、自己解题”的局限；本轮不验证自由传播、闪烁、真实标定或实时硬件链路。

## 事前统计方案

每回合先平均全部帧；同天气内三湍流类型等权，原策略三初始化等权，当前方法九组合等权。**独立统计单元按 8 份整天气，而不是 1,248 回合或 249,600 连续帧。** 不按未来安全、测量质量或收益筛掉回合。

分别报告每噪声档：原策略减积分器、当前方法减积分器、当前方法减原策略的绝对功率差；前两项另报相对积分器增量。相对收益是“平均功率差 ÷ 平均积分器功率”，不是逐回合百分比的平均。提供各天气差值、全部 13 分支均值、三类型分组和质量/安全/延迟指标。

使用固定 4 模型折的整天气分层自助重采样（bootstrap）：每折 2 天气有放回抽 2 份，5,000 次；所有比较共享抽样索引。另对 3 个非零噪声档分别报告相对零噪声的各方法功率变化、当前方法绝对增量变化、相对增量变化，保留配对和各档自己的积分器分母。

95% 区间是**逐项描述性区间**，仅反映这 8 份开发天气在固定模型/折路由下的变化；不是同时覆盖全部比较的区间，不提供训练不确定性、总体统计功效保证或多重比较显著性结论。每折仅两份天气，区间可能不稳定；只看某一个有利指标不足以宣称鲁棒性。

本轮没有新的 1%/1.05% 放行线，不改判历史确认或失败。功率改善不代表观测质量/安全合格，亦不保证每条天气或每个模型都改善。

## 完整性与停止条件

旧 D2 完整/快速输出共 486 个产物、D1 16 个、C 426 个、B 34 个及 C1 55 个固定文件和源码包必须保持指纹一致。只读封存元数据和指定权重，不打开旧确认轨迹，不重新拟合数据。

- 完成时回合/计数网格不得丢失、重复或缩短；全部记录有限值，回放误差不超过 `1e-6`。
- 零噪声最大模态误差目标 `0.001` 弧度；非零档均方根误差均值目标 `0.01`、95% 分位目标 `0.02` 弧度。它们是技术观测目标，不是补偿收益门槛，不决定动作选择。
- 任一动态读数拒绝或程序异常立即终止，保存 `failure.json`、已有日志和未完成回合/已发请求；不回退真值、不跳过、不自动重试。
- 仅汇总质量目标未满足时，照实记录 `targets_met=false`，不能修改读数或把完成标记解释为研究通过。
- 原请求与实际动作分别记录；受限诊断量沿用 `max(模态裁剪比例, 像素饱和比例, 像素变化限幅比例)`。它不是失败回合率，非零不应忽略。
- 已有输出触发保护；不删除旧目录、覆盖、改种子补考或自动恢复。
